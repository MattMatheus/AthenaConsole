# Story: Build Artifact Gallery and Preview UI

**As an Operator, I want a visual way to inspect agent outputs so that I can verify their work without downloading files.**

## Problem Statement
Agents produce many files (logs, code, images). Downloading these one-by-one to verify them is a major friction point.

## Acceptance Criteria
- "Gallery" view in the Session Explorer.
- Thumbnails/Icons based on file extension.
- Full-screen "Quick Look" for:
    - Code: Syntax highlighted view.
    - Markdown: Rendered human-readable view.
    - Images: High-resolution preview.
- "Audit Trail" link: Clicking an artifact shows exactly which turn in the transcript produced it.

## Technical Constraints
- Use a robust syntax highlighting library (e.g., `shiki` or `prism`).
- Large artifacts should be lazy-loaded to keep the UI snappy.
