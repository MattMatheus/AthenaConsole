# Story: Extract 'Runs' and 'Sessions' Route Handlers

**As a backend developer, I need to extract the API logic for the 'runs' and 'sessions' route families into the new `APIRouter`.**

## Acceptance Criteria
*   A new file (e.g., `src/api/routes/run-routes.ts`) is created for the handlers.
*   All logic for handling run and session management endpoints is moved into the new file.
*   These handlers are registered in the main `RouteTable`.
*   The old logic is removed from the original monolithic function.
*   Existing API tests for these endpoints continue to pass.
