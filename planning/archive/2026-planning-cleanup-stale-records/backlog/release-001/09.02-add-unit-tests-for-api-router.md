# Story: Add Unit Tests for API Router

**As a backend developer, I need comprehensive unit tests for the new `APIRouter` to ensure its matching logic is robust before migrating routes.**

## Acceptance Criteria
*   Unit tests are created for the `APIRouter` class.
*   Tests verify correct handler dispatch for static paths and parameterized paths.
*   Tests verify correct handling of different HTTP methods.
*   Tests confirm that an appropriate error (e.g., 404 Not Found) is returned when no route matches the request.
