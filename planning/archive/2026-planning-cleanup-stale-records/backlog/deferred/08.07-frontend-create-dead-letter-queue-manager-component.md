# Story: [Frontend] Create Dead-Letter Queue Manager Component

**As an operator, I want a UI to manage failed messages in the Dead-Letter Queue so I can ensure system reliability.**

## Status
*   **Blocked.** Depends on the backend API from `08.06`.

## Acceptance Criteria
*   A new UI component (`DeadLetterQueueManager.tsx`) is created.
*   It lists messages from the DLQ API.
*   Each message has buttons to trigger the "re-queue" and "delete" actions.
*   The UI provides feedback on the success or failure of these actions.
