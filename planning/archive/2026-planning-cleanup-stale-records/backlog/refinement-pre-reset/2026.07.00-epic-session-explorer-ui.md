# Epic: Session Explorer & Debugging UI

**As a Persona Developer, I want an interactive session explorer so that I can debug agent reasoning and inspect artifacts in real-time.**

## Problem Statement
Debugging agent behavior is currently a manual process of parsing JSON logs. Developers need a rich, visual environment to see how an agent arrived at a conclusion and to inspect the artifacts it produced.

## Success Metrics
- **Live Stream:** Transcripts update in real-time as the agent works.
- **Artifact Inspector:** Rich previews for code, markdown, and image artifacts.
- **Traceability:** One-click navigation from a finding back to the specific turn and context that produced it.

## Included Stories (Proposed)
- `2026.07.01-implement-real-time-transcript-streaming-api`
- `2026.07.02-build-session-explorer-and-transcript-viewer-ui`
- `2026.07.03-implement-artifact-gallery-and-file-preview`
