## User Story

As a Team Orchestrator operator, I need mission run history to remain inspectable after the current console session so mission execution outcomes can be reviewed later.

## Scope

Add the first mission-run history path for listing mission runs and opening mission-run detail from the mission workbench.

## Acceptance Criteria

- Adds an API/service path to list mission runs for a mission, including status, timestamps, backend, and child run count.
- Preserves the existing `GET /api/v1/mission-runs/:runId` detail path.
- Shows recent mission runs in the mission workbench for the selected mission.
- Links each listed mission run to a mission-run detail view or an equivalent detail panel.
- Shows child task run ids/statuses and links child task runs to existing task-run inspection.
- Preserves mission run creation, workflow-template instantiation, manual task creation, and task-run inspection behavior.

## Non-Goals

- No live streaming mission run timeline.
- No DAG execution UI.
- No mission retry policy.
- No retention policy controls.
