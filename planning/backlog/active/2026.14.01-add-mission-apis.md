## User Story

As a Team Orchestrator operator, I need mission APIs so I can group ordered tasks under a shared goal and context before mission execution is automated.

## Scope

Expose the first mission service/API surface for creating missions, ordering tasks, and listing mission tasks.

## Acceptance Criteria

- Creates missions with title, shared goal, and context.
- Gets and lists missions with deterministic status and ordering.
- Adds existing tasks to a mission.
- Creates new tasks inside a mission when requested by the API contract.
- Stores mission task order in the mission record.
- Stores task `missionId` and preserves existing task `dependsOn: string[]` metadata.
- Lists mission tasks in mission order, with unordered or newly attached tasks handled deterministically.
- Includes focused core API/service tests for mission creation, task attachment, task creation inside a mission, dependency metadata, and mission task listing order.

## Non-Goals

- No mission run execution.
- No workflow template indexing.
- No full DAG scheduler.
- No console mission UI.
- No natural-language task planner.
