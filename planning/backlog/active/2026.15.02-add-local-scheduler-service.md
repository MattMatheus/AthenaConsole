## User Story

As a Team Orchestrator operator, I need the local API service to run due task schedules so configured repeatable work can execute while the app is running.

## Scope

Add the first local due-schedule execution path for task-target schedules stored in SQLite.

## Acceptance Criteria

- Adds a core service/API path that finds due active task schedules at a supplied or current time.
- Runs due task schedules through the existing task workbench execution path.
- Records schedule provenance on created task runs where the current model supports it.
- Updates `lastRunId`, `nextRunAt`, status, and failure policy metadata after schedule attempts.
- Skips missed runs by default rather than catching up multiple occurrences.
- Uses `skip-if-running` as the default overlap policy.
- Emits or records enough missed/skipped/run status detail for later UI/history work.
- Includes focused tests for due execution, skipped non-due schedules, failed task runs, and next-run updates.

## Non-Goals

- No always-on background worker loop.
- No hosted scheduler.
- No schedule UI.
- No mission or workflow-template schedules.
- No catch-up policy beyond skipped missed runs.
