## User Story

As a Team Orchestrator operator, I need to instantiate a workflow template from the console so plugin-provided repeatable work can become visible missions and tasks without calling the API by hand.

## Scope

Add the first console workflow template instantiation surface using the core instantiation API.

## Acceptance Criteria

- Exposes an operator path from the workflow template catalog to instantiate an available template.
- Shows template identity, plugin identity, description, task count, and workflow goal/context preview where available.
- Presents template input fields from catalog metadata when definitions exist and honors defaults.
- Calls `POST /api/v1/workflow-templates/:id/instantiate` with supplied inputs and optional disambiguation metadata.
- Shows the created mission id, generated task ids, and direct links to existing mission/task views where available.
- Handles unavailable templates, API validation failures, and required input errors without disrupting the catalog list.
- Preserves existing catalog, mission, task, schedule, and run inspection behavior.

## Non-Goals

- No workflow-template editing.
- No workflow-template scheduling.
- No full DAG mission execution UI.
- No plugin install or remote registry UI.
