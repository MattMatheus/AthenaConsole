# M5.06: Implement Cost Governance and Resource Quotas

**As a Platform Owner, I want to implement cost governance and resource quotas, so that we don't unexpectedly exhaust our Azure Startup Credits.**

### Problem Statement
Agent-driven workloads can be resource-intensive. Without strict limits, a runaway loop could consume our entire credit allocation or overwhelm the AKS cluster.

### User Persona
- **Alex (Platform Engineer):** Needs to safeguard the subscription and ensure fair resource distribution.

### Acceptance Criteria
- [ ] Azure Budget configured for the Resource Group with alerts at 50%, 75%, and 90% of the monthly allocation.
- [ ] Kubernetes `ResourceQuota` and `LimitRange` objects applied to the execution namespaces to cap CPU and Memory usage per persona run.
- [ ] Automated cleanup script or policy for orphaned K8s Jobs and aged Persistent Volume Claims (PVCs).
- [ ] Cost visualization enabled in the Athena Admin Dashboard (using Azure Billing API).

### Risks & Assumptions
- **Risk:** Overly restrictive quotas might cause persona runs to fail during peak usage.
- **Assumption:** The Azure Billing API is accessible via the service principal/managed identity.
