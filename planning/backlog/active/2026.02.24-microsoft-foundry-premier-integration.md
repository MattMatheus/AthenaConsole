# M4.04: Implement Microsoft Foundry as Premier Model Provider

**As the Platform Owner, I want to integrate Microsoft Foundry as our primary model provider, so that we can utilize our $1,000 AI startup credit and establish a professional-grade, Azure-native identity and governance path.**

### Problem Statement
Currently, Project Athena defaults to a standard OpenAI-compatible provider. To maximize our startup credits and align with our strategic architecture (ADR 0005), we must make Microsoft Foundry the premier integration path. This requires a dedicated provider adapter, Entra ID authentication support, and configuration updates to make it the default choice for the orchestrator.

### User Persona
- **Alex (Platform Engineer):** Needs to manage model costs and identity-based access control.
- **Sam (Developer):** Needs to use the high-performance Foundry models without manually configuring API keys.

### Acceptance Criteria
- [ ] A new `FoundryProviderAdapter` is implemented in `packages/core/src/providers/foundry.ts`.
- [ ] The `FoundryProviderAdapter` supports both Entra ID (via `DefaultAzureCredential`) and API Key authentication.
- [ ] The `ProviderRegistry` is updated to include the `foundry` provider.
- [ ] `AthenaConfig` is expanded to include all Foundry-specific environment variables as defined in ADR 0005.
- [ ] The system defaults to `foundry` as the primary provider with `openai` as the fallback.
- [ ] Unit tests verify the adapter's ability to construct correct inference endpoints and map responses to `RunResult`.
- [ ] Developer documentation is updated with instructions for local developers to authenticate with Azure (e.g., `az login`) to use the Foundry provider.

### Risks & Assumptions
- **Risk:** Entra ID token acquisition might be slow or fail in certain local environments.
- **Mitigation:** Classify token errors and ensure seamless fallback to the `openai` provider if configured.
- **Assumption:** The Microsoft Foundry inference API follows the expected standard for the adapter implementation.
