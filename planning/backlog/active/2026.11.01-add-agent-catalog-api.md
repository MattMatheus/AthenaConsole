## User Story

As a Team Orchestrator operator, I need an API/service surface for indexed plugins and agents so the console can show what local agents are installed, valid, and available for tasks.

## Scope

Expose the local plugin and agent index through core services and API routes suitable for the console.

## Acceptance Criteria

- Lists indexed plugins and agents from SQLite app state.
- Filters agents by capability.
- Returns manifest-derived metadata needed by the console catalog.
- Returns plugin and agent validation/load errors.
- Distinguishes system and workspace plugin sources.
- Includes focused tests for service behavior, API response shape, filtering, and error visibility.
- Keeps implementation aligned with local-first defaults.

## Non-Goals

- No console UI page.
- No plugin install/registry flow.
- No remote plugin source.
- No task creation flow.
- No agent execution changes.

## Validation Expectations

- `npm --workspace @athena/core run typecheck`
- Focused core tests for the new catalog API/service behavior.
- `npm --workspace @athena/core run test:unit` if shared API or control-plane surfaces are touched broadly.
