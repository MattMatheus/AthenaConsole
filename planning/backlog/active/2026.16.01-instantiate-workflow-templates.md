## User Story

As a Team Orchestrator operator, I need to instantiate a workflow template into a mission and ordered tasks so repeatable plugin-provided work can become executable local work.

## Scope

Add the first API/service path that turns an indexed workflow template into a mission with task records.

## Acceptance Criteria

- Adds a core service/API path to instantiate a workflow template by id.
- Resolves template-level inputs into mission context and task inputs using explicit bindings or defaults where present.
- Creates a mission with title/goal/context derived from the template.
- Creates ordered tasks with capability requirements, agent hints where they can map to current assignment fields, dependencies, and provenance pointing back to the workflow template.
- Returns the created mission and task summaries.
- Preserves existing mission/task APIs and sequential mission run behavior.
- Includes focused tests for successful instantiation, missing template, missing required inputs, task dependency preservation, and provenance.

## Non-Goals

- No console workflow template instantiation UI yet.
- No natural-language task planning.
- No full DAG mission execution.
- No workflow-template schedules.
- No remote plugin registry.
