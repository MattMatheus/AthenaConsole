## User Story

As a Team Orchestrator operator, I need task API/service surfaces so the console can create, assign, list, and move manual tasks through draft and ready states.

## Scope

Expose the existing SQLite task repository through core services and API routes suitable for the console task workbench.

## Acceptance Criteria

- Creates draft tasks.
- Assigns compatible agents.
- Validates `ready` status requires an assigned agent.
- Lists tasks by status.
- Returns task metadata needed by the manual task create flow.
- Includes focused tests for service behavior, API response shape, assignment validation, and status filtering.

## Non-Goals

- No console task creation UI.
- No task execution flow.
- No mission DAG execution.
- No scheduling UI.
- No remote hosted execution.

## Validation Expectations

- `npm --workspace @athena/core run typecheck`
- Focused core tests for the new task API/service behavior.
- `npm --workspace @athena/core run test:unit` if shared API or control-plane surfaces are touched broadly.
