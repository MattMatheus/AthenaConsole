# Story: Implement Egress Filtering and Network Policies

**As a Security Admin, I want to prevent agents from exfiltrating data to unauthorized websites.**

## Problem Statement
Agents shouldn't be allowed to "call home" or send repo secrets to arbitrary URLs. We need strict network egress control.

## Acceptance Criteria
- Default policy is `Deny All` egress.
- `HarnessProfile` supports an `allowedEgress` list (domains or IPs).
- **K8s:** Automatically generates a `NetworkPolicy` for the ephemeral Pod.
- **Docker:** Uses internal bridge networking with iptables or proxy filtering.
- Unauthorized connection attempts are logged for security auditing.

## Technical Constraints
- Must handle DNS resolution correctly within the sandbox.
- Ensure that the agent can still reach the LLM provider (if routed through the sandbox) or the Team Orchestrator API.
