# Story: Build Admin Dashboard Frontend Scaffold

**As a Platform Operator, I want a web UI so that I can manage Team Orchestrator without using the CLI.**

## Problem Statement
The CLI is powerful but lacks the "at-a-glance" visibility needed for fleet management. We need a modern web-based dashboard for observability and governance.

## Acceptance Criteria
- React/TypeScript frontend application scaffolded in `src/ui` (or separate package).
- Integrated into the Team Orchestrator build process (`npm run build` builds the UI).
- Includes a "Fleet Status" home page using the Aggregation API.
- Implements basic navigation (Sessions, Fleet, Policy, Workflows).
- Respects Team Orchestrator RBAC: Viewers cannot see administrative settings.

## Technical Constraints
- Use a lightweight UI kit (e.g., Tailwind or Bootstrap) for rapid development.
- The UI should be served by the Team Orchestrator API server in "standalone" mode.
