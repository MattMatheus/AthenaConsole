# Epic: Workflow DAG Engine

**As a Workflow Architect, I want to orchestrate multi-step agent tasks so that I can automate complex engineering processes.**

## Problem Statement
Team Orchestrator is currently "one-and-done." Complex tasks that require multiple specialized agents working in sequence must be managed manually by the user, which is inefficient and brittle.

## Success Metrics
- **Dependency Management:** Step B only starts if Step A completes successfully.
- **State Passing:** Output from Step A is automatically available as context for Step B.
- **Resilience:** If Step C fails, the operator can fix the issue and resume the workflow from Step C.

## Included Stories (Proposed)
- `26.01-implement-workflow-dag-definition-parser`
- `26.02-implement-workflow-state-store-and-resumption-logic`
- `26.03-add-visualizer-friendly-workflow-status-api`
