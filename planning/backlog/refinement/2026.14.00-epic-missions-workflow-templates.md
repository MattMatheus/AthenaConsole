# Epic: Missions and Workflow Templates

## Status

Refinement.

## Goal

Compose tasks into repeatable ordered missions and plugin-provided workflow templates.

## Source Decisions

- `planning/architecture/0008-plugin-package-format.md`
- `planning/architecture/0009-task-mission-run-domain-model.md`
- `planning/architecture/0011-runtime-backend-interface.md`

## Candidate Stories

### 2026.14.01 Add Mission APIs

Expose mission creation, task ordering, dependency metadata, and mission status.

Acceptance criteria:

- Creates missions with shared goal/context.
- Adds existing or new tasks to missions.
- Stores `dependsOn: string[]`.
- Lists mission tasks in order.

### 2026.14.02 Add Workflow Template Indexing

Index plugin-provided workflow templates.

Acceptance criteria:

- Validates workflow template manifests.
- Stores template metadata in SQLite.
- Shows validation/load errors.

### 2026.14.03 Run Sequential Mission Plans

Run mission tasks in sequence.

Acceptance criteria:

- Creates child task runs.
- Stops on failed task by default.
- Records mission run lineage.
- Preserves manual task runs as first-class.

## Non-Goals

- No full DAG scheduler in the first mission implementation.
- No natural-language task planner.
