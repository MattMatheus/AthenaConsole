# Epic: Containerized Execution Backends

**As a Security Engineer, I want agents to run in ephemeral containers so that they cannot compromise the host system.**

## Problem Statement
The current local execution backend runs commands on the host machine. This is unacceptable for production use cases where agents might generate and execute untrusted code. We need true process and filesystem isolation.

## Success Metrics
- **Zero-Persistence:** Each run gets a clean, ephemeral container.
- **Multi-Backend Support:** Support for both Docker (local dev) and K8s (production).
- **Hardened Defaults:** No root access, no host network access, and restricted syscalls by default.

- `28.03-add-workspace-mounting-and-sync-logic-for-containers`
