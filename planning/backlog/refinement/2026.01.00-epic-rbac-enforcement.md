# Epic: RBAC Enforcement & Authorization Migration

**Goal:** Secure the Project Athena control plane by implementing a granular, scope-aware Role-Based Access Control (RBAC) system at the service layer.

## Overview
As Project Athena transitions from a local tool to a multi-operator digital workforce platform, security and auditability become critical. This epic covers the transition from "identity awareness" to "full enforcement" of the permission model defined in the Stage 8 Architecture.

## Key Outcomes
- Granular `<resource>:<action>` controls for all API/Service operations.
- Mission-level isolation via Scoped Access (Persona/Session/Run).
- Safe rollout path through `observe` and `soft-enforce` modes.
- Comprehensive audit trails for all authorization decisions.
