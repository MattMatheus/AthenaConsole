# Epic: Verification & Evidence Model

**As a Compliance Officer, I want agents to provide verifiable evidence of their work so that I can trust their outputs.**

## Problem Statement
We currently rely on the LLM to "say" it passed a review or fixed a bug. In production, we need proof (e.g., "Here is the log showing the test passed") and a way to verify that proof programmatically.

## Success Metrics
- **Evidence Collection:** Tools can attach "evidence" (blobs, logs, metrics) to a run.
- **Verification Gates:** A run cannot be marked `pass` unless all required evidence is present and valid.
- **Auditability:** Evidence bundles are stored alongside `result.json` for long-term review.
