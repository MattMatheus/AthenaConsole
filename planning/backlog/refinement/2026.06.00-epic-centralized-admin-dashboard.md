# Epic: Centralized Admin Dashboard

**As a Platform Operator, I want a centralized web UI so that I can monitor fleet health and resource consumption at a glance.**

## Problem Statement
Operating a fleet of agents via CLI is impossible at scale. We need a "Control Tower" that provides aggregate metrics on success rates, resource utilization, and operational costs.

## Success Metrics
- **Real-time Health:** A dashboard showing the status of all Team Orchestrator nodes and active runs.
- **Resource Visibility:** Aggregated CPU/Memory and token usage charts.
- **Cost Attribution:** Reports showing LLM spend broken down by persona and project.
