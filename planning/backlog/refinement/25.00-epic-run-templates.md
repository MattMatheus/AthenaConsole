# Epic: Run Templates

**As an Operator, I want parameterized job templates so that I can trigger repeatable automation with minimal configuration.**

## Problem Statement
Standard operations (like a nightly security audit) require the user to provide the same complex CLI flags every time. This is error-prone and prevents non-expert users from interacting with the platform.

## Success Metrics
- **Template Library:** A searchable set of `RunTemplates`.
- **Parameter Injection:** Templates support variables (e.g., `{{BRANCH_NAME}}`).
- **Standardization:** All runs for a specific business process use the exact same Harness and Safety policies.

## Included Stories (Proposed)
- `25.01-implement-parameterized-run-template-schema`
- `25.02-create-template-trigger-api-endpoint`
- `25.03-add-cli-support-for-template-based-runs`
