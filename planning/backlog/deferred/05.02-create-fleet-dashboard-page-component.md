# Story: Create Fleet Dashboard Page Component

**As a frontend developer, I need to create a main `FleetDashboard` page component that serves as the container for all fleet monitoring visualizations.**

## Acceptance Criteria
*   A new page component (`FleetDashboard.tsx`) is created and integrated into the UI routing.
*   The component uses the `FleetApiService` to fetch data.
*   It handles and displays loading and error states.
*   It lays out the child components for summary, resources, etc.
