# Story: [Frontend] Update UI to Use Cursor-Based Pagination

**As a frontend developer, I need to update all UI components that display historical data to use the new cursor-based pagination APIs.**

## Status
*   **Blocked.** Depends on the backend implementation from `14.02`.

## Acceptance Criteria
*   All UI components that show lists of historical runs are updated.
*   The components now use the `cursor` parameter to fetch subsequent pages instead of an offset or page number.
*   The "load more" or "next page" logic correctly uses the `nextCursor` provided by the API.
*   The user experience for paginating through data remains smooth.
