# Story: Create Session API Service for UI

**As a frontend developer, I need a `SessionApiService` to handle all API calls related to fetching session data, including transcripts, work queues, and artifacts.**

## Acceptance Criteria
*   A new service file (`ui/src/services/SessionApiService.ts`) is created.
*   The service includes methods to fetch data for a specific session ID (e.g., `getSessionTranscript(id)`, `getSessionWorkQueue(id)`).
*   It uses the API contracts for type-safe data handling.
*   It includes robust error handling.
