# Story: Create Work Queue Component

**As a developer, I want to inspect an agent's work queue, separated by status (Pending, Completed, Failed), so I can diagnose task execution issues.**

## Acceptance Criteria
*   A new component (`WorkQueue.tsx`) is created.
*   It takes the session's work queue data as a prop.
*   It displays the tasks in lists or tables, grouped by their status.
*   Each task entry shows its key details.
