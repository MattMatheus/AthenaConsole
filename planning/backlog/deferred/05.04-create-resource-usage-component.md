# Story: Create Resource Usage Component

**As an operator, I want a component on the dashboard that visualizes the aggregate CPU and Memory consumption of the fleet, so I can monitor resource utilization.**

## Acceptance Criteria
*   A new component (`ResourceUsage.tsx`) is created.
*   It visualizes the CPU and Memory data from the `FleetSummary` (e.g., with gauges or bar charts).
*   It respects the `capabilities.supportsCpuMemMetrics` flag; if the flag is false, it displays a message indicating that the metrics are not available from the current backend.
