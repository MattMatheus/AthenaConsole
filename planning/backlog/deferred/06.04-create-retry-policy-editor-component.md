# Story: Create Retry Policy Editor Component

**As an admin, I want a form in the Policy Editor to configure task retry and backoff rules, so that I can improve system resilience.**

## Acceptance Criteria
*   A new component (`RetryPolicyEditor.tsx`) is created.
*   The component includes form fields for setting the number of retry attempts and the backoff strategy (e.g., a dropdown for 'fixed', 'exponential').
*   It uses the `PolicyApiService` to load and save the retry policy.
