# Story: Create Session Transcript Component

**As a developer, I want to see the real-time transcript of an agent's session in a readable format, so I can debug its behavior.**

## Acceptance Criteria
*   A new component (`SessionTranscript.tsx`) is created.
*   It takes the session transcript data as a prop and renders it in a chat-like, easy-to-read format.
*   The component should automatically poll for updates to provide a near-real-time view of the transcript.
