# Story: Create Policy API Service for UI

**As a frontend developer, I need a `PolicyApiService` to abstract all interactions with the backend policy endpoints, so that my UI components can manage policies in a consistent way.**

## Acceptance Criteria
*   A new service file (`ui/src/services/PolicyApiService.ts`) is created.
*   The service has methods for fetching and updating various policy objects (e.g., concurrency, retry, timeout).
*   It uses the API contracts for type safety.
*   It provides clear error handling for API failures.
