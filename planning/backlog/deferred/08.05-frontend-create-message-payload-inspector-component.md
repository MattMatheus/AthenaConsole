# Story: [Frontend] Create Message Payload Inspector Component

**As a developer, I want to inspect the payload of individual messages in real-time so I can debug data formats.**

## Status
*   **Blocked.** Depends on the backend API from `08.04`.

## Acceptance Criteria
*   A new UI component (`MessagePayloadInspector.tsx`) is created.
*   It connects to the message tailing API and displays a live-updating list of message payloads.
*   Each message is displayed in a readable format (e.g., a formatted JSON viewer).
