# Story: Create Fleet Status Summary Component

**As an operator, I want a high-level summary component on the dashboard that shows me the total number of agents and their current status (Running, Pending, etc.) so I can get an instant overview of fleet health.**

## Acceptance Criteria
*   A new component (`FleetStatusSummary.tsx`) is created.
*   It receives `FleetSummary` data as a prop.
*   It displays the total agent count and the breakdown by status in a clear, at-a-glance format (e.g., using cards or stat blocks).
