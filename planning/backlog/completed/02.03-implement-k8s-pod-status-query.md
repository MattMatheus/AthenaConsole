# Story: Implement K8s Pod Status Query

**As a developer, I want the `K8sMetricsProvider` to query the Kubernetes API for agent pods and translate their phase into the `FleetSummary` status counts so that we have real-time agent status from the cluster.**

## Acceptance Criteria
*   The provider uses `@kubernetes/client-node` to list pods that match the application's agent labels.
*   The Kubernetes pod phases (`Pending`, `Running`, `Succeeded`, `Failed`) are correctly mapped to the corresponding fields in the `FleetSummary` contract.
*   The `total` count reflects the total number of agent pods found.
*   The implementation includes error handling for when the Kubernetes API is unavailable.
