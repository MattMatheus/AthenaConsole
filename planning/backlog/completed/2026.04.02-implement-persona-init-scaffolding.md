# Story: Implement 'athena persona init' Scaffolding

**As a New Developer, I want to scaffold a new persona with one command so that I can start building immediately.**

## Problem Statement
Starting a new persona requires manually creating 4-5 files and matching the folder structure. This is a barrier to entry for new users and teams.

## Acceptance Criteria
- CLI command `athena persona init <name>` implemented.
- Generates a directory under `personas/` with:
    - `persona.json` (basic config).
    - `prompt.md` (system prompt template).
    - `skills.md` (skill definitions).
    - `docs.md` (persona documentation).
- Asks interactive questions (e.g., "What is the primary role of this agent?") to populate the templates.
- The generated persona passes `athena persona validate` immediately after creation.

## Technical Constraints
- Use a template-based generation system (e.g., `handlebars` or simple string replacement).
- Ensure the scaffolding respects the project's existing linting and formatting rules.
