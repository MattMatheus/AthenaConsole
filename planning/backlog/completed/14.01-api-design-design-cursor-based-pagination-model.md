# Story: [API Design] Design Cursor-Based Pagination Model

**As an API designer, I need to design a cursor-based pagination model for our timeline APIs to ensure stable and consistent pagination, even under high write churn.**

## Scope
*   Define a standard API envelope for cursor-paginated responses, including a `nextCursor` field.
*   Define the query parameters (`limit`, `cursor`) for requesting pages.
*   Determine the best field or combination of fields to use as a stable, sequential cursor (e.g., a combination of a timestamp and a unique ID).
*   The deliverable is an API design document or an update to our existing API standards.
