# Story: Define Fleet Summary Contract

**As a developer, I want a stable, versioned TypeScript interface for `FleetSummary` so that all metric providers can adhere to a single, predictable data schema.**

## Status
Completed on 2026-02-17.

## Acceptance Criteria
*   A `FleetSummary` interface is defined in `src/control-plane/api-contracts.ts`.
*   The interface includes fields for total agents, and counts for agents in `Running`, `Pending`, `Succeeded`, and `Failed` states.
*   The interface is versioned or clearly marked as part of the v1 API.
*   The interface includes placeholder fields for optional metrics like `cpuUsage` and `memoryUsage`, which can be populated by capable providers.
