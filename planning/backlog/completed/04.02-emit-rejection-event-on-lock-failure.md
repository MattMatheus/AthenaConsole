# Story: Emit Rejection Event on Lock Failure

**As a developer, I want to emit a `RunRejectionEvent` whenever the distributed lock for a new run cannot be acquired, so that all concurrency rejections are captured for auditing.**

## Acceptance Criteria
*   The run submission workflow that handles `IDistributedLock` failures is modified.
*   Upon failure to acquire a lock, it instantiates a `RunRejectionEvent` with the relevant details.
*   The event is passed to a new `RejectionEventService` (or similar) for processing and storage.
*   This behavior is covered by an integration test.
