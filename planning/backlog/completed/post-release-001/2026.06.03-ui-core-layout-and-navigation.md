# Story: UI Core Layout and Navigation

**As a User, I want a consistent navigation structure so that I can quickly move between the Dashboard, Sessions, and System Settings.**

## Problem Statement
The console needs a "Shell" that provides global context. This includes a sidebar for primary navigation and a header for identity/auth status and breadcrumbs.

## Acceptance Criteria
- Implement `AppLayout` component with:
    - **Toggleable Sidebar:** Left-side navigation with a "Hamburger" menu in the header to show/hide the panel.
    - **Sidebar Navigation:** Links to `Dashboard`, `Sessions`, `Workflows`, `Resources` (Directives/Harnesses), and `Settings`.
    - **Header:** Displays the current page title, breadcrumbs, and a "Global Search" bar for Run/Session IDs.
    - **Central Detail Pane:** A robust area for content that supports nested, collapsible sections (Accordions) for dense metadata.
- **Stateful Navigation:** Sidebar visibility should be persisted in local storage.
- **Responsive Design:** Sidebar should default to "Hidden" on mobile viewports.
- **Visual Polish:** Use a monospaced font for IDs and code snippets to maintain the engineering aesthetic.

## Technical Constraints
- Use `react-router-dom` for client-side routing.
- All layout components must use CSS Modules for scoping.
- Icons should be SVG-based (e.g., `lucide-react` or similar lightweight package).
