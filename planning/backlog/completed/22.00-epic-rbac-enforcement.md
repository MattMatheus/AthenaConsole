# Epic: RBAC Enforcement

**As a Security Admin, I want all API resources protected by RBAC so that I can limit who can trigger runs and modify platform policies.**

## Problem Statement
The RBAC design is complete (ADR-15), but the code-level enforcement is missing. Any user with network access to the API can perform administrative actions.

## Success Metrics
- **Identity Extraction:** Middleware correctly identifies the caller.
- **Resource Authorization:** Every controller/service check verifies `<resource>:<action>` permissions.
- **Audit Logs:** Every unauthorized attempt is recorded in the event store.

## Included Stories (Proposed)
- `22.01-implement-identity-extraction-middleware`
- `22.02-enforce-rbac-on-policy-and-run-endpoints`
- `22.03-enforce-rbac-on-persona-and-schedule-management`
