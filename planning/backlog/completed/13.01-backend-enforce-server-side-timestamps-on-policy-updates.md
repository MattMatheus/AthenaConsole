# Story: [Backend] Enforce Server-Side Timestamps on Policy Updates

**As a backend developer, I need to modify the policy update API to ignore any client-provided `updatedAt` value and overwrite it with the server's current time.**

## Acceptance Criteria
*   The API endpoint for creating/updating policies is modified.
*   Before saving a policy object, the `updatedAt` field is always set to the current server timestamp.
*   Any `updatedAt` value in the incoming request payload is ignored.
*   The change is deployed without causing errors for existing clients.
