# Story: Implement Comprehensive RBAC Coverage

**As a Security Administrator, I want all system resources to be protected by RBAC to ensure the principle of least privilege.**

## Problem Statement
The current RBAC implementation only covers a subset of services (Run, Policy, Schedule). Other resources like Sessions, Directives, Workflows, and Memory remain open to any authenticated user regardless of their role.

## Acceptance Criteria
- Implement `Authorized` service wrappers for:
    - `SessionService`: `list/get/transcript` requires `Viewer`.
    - `DirectiveService`: `list/create` requires `Operator` or `Admin`.
    - `WorkflowService`: `list/status/resume` requires `Operator` or `Admin`.
    - `WorkService`: `enqueue/drain/status` requires `Operator` or `Admin`.
    - `MemoryService`: `search/get` requires `Viewer`.
    - `EventService`: `list` requires `Viewer`.
    - `A2aDlqService`: `list` requires `Viewer`, `requeue/discard` requires `Operator` or `Admin`.
- Update `createLocalControlPlaneServices` in `src/control-plane/services.ts` to wire all services with their authorized decorators.
- Ensure `Admin` role has `admin` permission across all resources.

## Technical Constraints
- Every method call in `ControlPlaneServices` must be audited through the `ServiceAuthorizer`.
- No authorization logic should remain in the raw `Local*` service implementations.
