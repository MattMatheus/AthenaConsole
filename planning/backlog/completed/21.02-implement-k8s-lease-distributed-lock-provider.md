# Story: Implement K8s Lease Distributed Lock Provider

**As a K8s Operator, I want a zero-dependency locking provider using native K8s Leases.**

## Problem Statement
Deploying Redis just for locking adds operational overhead. Kubernetes provides a native `Lease` API that is designed specifically for this type of distributed coordination.

## Acceptance Criteria
- New `K8sLeaseLockProvider` implemented.
- Uses `@kubernetes/client-node` to create/update `coordination.k8s.io/v1` Lease objects.
- Uses the lease `holderIdentity` for ownership tracking.
- Automatically cleans up expired leases.
- Default to the current namespace of the Athena pod.

## Technical Constraints
- Requires `create`, `get`, `update`, and `delete` permissions on `leases` in the RBAC profile.
- Must respect the global lease duration configured in Athena policy.
