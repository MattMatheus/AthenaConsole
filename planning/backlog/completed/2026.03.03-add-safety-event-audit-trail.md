# Story: Add Safety Event Audit Trail

**As a Security Auditor, I want a permanent record of all safety violations.**

## Problem Statement
When an agent attempts to breach a sandbox or exceed a quota, it is a critical security event. We need a detailed audit trail of these attempts for post-mortem analysis.

## Acceptance Criteria
- Every safety-driven termination is logged to the `EventService`.
- Events include:
    - Persona name and user identity.
    - Specific limit breached (CPU, Network, Filesystem).
    - Violation details (e.g., the URL the agent tried to reach).
    - Snapshot of the agent's reasoning (transcript) leading up to the violation.
- High-severity safety events trigger an alert (to stdout or external webhook).

## Technical Constraints
- Ensure safety events cannot be suppressed by the agent.
- Events must be immutable and written to the persistent store.
