# Story: Implement Run Template Schema

**As an Operator, I want to define Run Templates so that I can trigger complex automation with simple parameter overrides.**

## Problem Statement
Many agent tasks are recurring (e.g., "Review branch X"). Instead of providing the full CLI command every time, we want to call a "Template" with just the branch name.

## Acceptance Criteria
- `RunTemplate` resource defined with:
    - `id`: Unique identifier.
    - `harnessProfileId`: Link to the agent config.
    - `directiveTemplate`: A directive with placeholders (e.g., `Review the changes in {{HEAD_REF}}`).
    - `defaultParams`: Default values for placeholders.
- Validation logic to ensure all placeholders in the directive template are accounted for.

## Technical Constraints
- Use a simple mustache-style or bracket-style placeholder syntax (e.g., `{{VAR}}`).
