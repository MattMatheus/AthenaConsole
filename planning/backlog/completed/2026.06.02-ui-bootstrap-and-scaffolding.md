# Story: UI Bootstrap and Scaffolding

**As a UI Engineer, I want a well-defined project structure and build pipeline so that I can develop components with type safety and fast feedback loops.**

## Problem Statement
We need to establish the foundation for the `@projectathena/console` package (or directory). This includes the choice of build tools, linting, and the initial set of CSS design tokens to ensure visual consistency from day one.

## Acceptance Criteria
- Project initialized using **Vite** (React + TypeScript).
- CSS System established:
  - Base `tokens.css` with CSS Variables for primary brand colors, semantic colors (success/error/warning), spacing, and typography.
  - Reset and global styles established.
- Directory structure:
  - `src/components/` (Shared UI atoms/molecules)
  - `src/features/` (Domain-specific logic: `fleet`, `sessions`, `runs`)
  - `src/hooks/` (Shared custom hooks)
  - `src/services/` (API client integration using TanStack Query)
  - `src/styles/` (Global CSS and CSS Modules)
- Development server starts and renders a "System Ready" landing page with basic branding.

## Technical Constraints
- No utility-first CSS frameworks (Tailwind). Use **CSS Modules**.
- Strict TypeScript configuration (`strict: true`).
- Ensure the build output is optimized for production (minified, code-split).
- Setup proxying for local API development (`/api` -> `localhost:3000`).
