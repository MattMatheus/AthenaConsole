## User Story

As a Team Orchestrator operator, I need a mission workbench in the console so instantiated and manually created missions can be inspected and run without using API calls.

## Scope

Add the first mission-focused console surface for listing missions, inspecting ordered tasks, and starting sequential mission runs.

## Acceptance Criteria

- Lists missions from `GET /api/v1/missions` with status, title, task count/order, updated timestamp, and archived filtering where supported.
- Shows a selected mission detail panel with goal, context preview, ordered tasks, task statuses, dependency hints, and links to task/run views where available.
- Calls `GET /api/v1/missions/:id/tasks` for mission task detail.
- Starts a mission run with `POST /api/v1/missions/:id/run` and surfaces child task run ids/statuses.
- Links workflow-template instantiation results to the mission workbench once it exists.
- Preserves manual task creation, task-run inspection, schedule management, and workflow-template instantiation behavior.

## Non-Goals

- No full DAG execution UI.
- No mission editing beyond existing API fields unless it is required for display.
- No workflow-template scheduling.
- No live streaming mission run timeline.
