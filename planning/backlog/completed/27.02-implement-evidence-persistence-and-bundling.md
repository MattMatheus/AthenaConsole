# Story: Implement Evidence Persistence and Bundling

**As an Auditor, I want evidence to be stored securely with the run artifacts so that I have a complete "Trust Bundle."**

## Problem Statement
If evidence is stored separately from the run result, the link between "Conclusion" and "Proof" can be lost. We need a unified artifact bundle.

## Acceptance Criteria
- All evidence for a run is stored in `.athena/persona-runs/<id>/evidence/`.
- The `result.json` includes an `evidenceManifest` containing IDs, labels, and SHA-256 checksums of all evidence.
- The CLI `athena run` output includes a summary of attached evidence count.

## Technical Constraints
- Use content-addressable storage or strict checksums to prevent evidence tampering.
