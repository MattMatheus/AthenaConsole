# Story: Implement Deterministic Route Precedence

**As a backend developer, I need to enhance the `APIRouter`'s matching logic to be fully deterministic, so that route collisions are handled predictably.**

## Acceptance Criteria
*   The `APIRouter`'s dispatch logic is modified to sort routes before matching.
*   The sorting algorithm prioritizes static paths over parameterized paths (e.g., `/runs/summary` before `/runs/:id`).
*   The sorting handles multiple parameters correctly (e.g., `/a/:b/c` before `/a/:b/:c`).
*   Unit tests for the router are updated to reflect this new, deterministic behavior.
