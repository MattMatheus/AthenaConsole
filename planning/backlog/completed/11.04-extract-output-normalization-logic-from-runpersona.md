# Story: Extract 'Output Normalization' Logic from runPersona

**As a backend developer, I need to extract the model output processing from `runPersona` into a new 'output normalization' function.**

## Acceptance Criteria
*   A new function (e.g., `normalizeOutput`) is created.
*   It is responsible for taking the raw, validated model output and transforming it into the final, expected output schema of `runPersona`.
*   `runPersona` is updated to call this new function.
*   Unit tests are added to cover the normalization logic.
