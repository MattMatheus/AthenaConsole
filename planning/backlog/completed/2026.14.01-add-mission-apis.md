## User Story

As a Team Orchestrator operator, I need mission APIs so I can group ordered tasks under a shared goal and context before mission execution is automated.

## Scope

Expose the first mission service/API surface for creating missions, ordering tasks, and listing mission tasks.

## Acceptance Criteria

- Creates missions with title, shared goal, and context.
- Gets and lists missions with deterministic status and ordering.
- Adds existing tasks to a mission.
- Creates new tasks inside a mission when requested by the API contract.
- Stores mission task order in the mission record.
- Stores task `missionId` and preserves existing task `dependsOn: string[]` metadata.
- Lists mission tasks in mission order, with unordered or newly attached tasks handled deterministically.
- Includes focused core API/service tests for mission creation, task attachment, task creation inside a mission, dependency metadata, and mission task listing order.

## Non-Goals

- No mission run execution.
- No workflow template indexing.
- No full DAG scheduler.
- No console mission UI.
- No natural-language task planner.

## Engineering Handoff

- Added shared mission workbench contracts for missions, mission list results, mission task list results, task attachment, and task creation inside missions.
- Added `LocalMissionWorkbenchService` backed by the existing SQLite mission/task repositories.
- Supports mission create/get/update/list with title, goal, context, status, and ordered task references.
- Supports attaching existing tasks to a mission, updating task `missionId`, preserving/setting `dependsOn`, and inserting task IDs into mission order.
- Supports creating new tasks inside a mission through the existing task workbench creation path so task validation remains consistent with `/api/v1/tasks`.
- Lists mission tasks in mission order and appends unordered mission tasks deterministically by creation time and ID.
- Added `/api/v1/missions` routes for list/create/get/update.
- Added `/api/v1/missions/:id/tasks` routes for list/create and `/api/v1/missions/:id/tasks/attach` for attaching existing tasks.
- Updated API route contracts, route registration, response schemas, and server route composition.
- Added focused service and API tests for mission creation, task attachment, mission task creation, dependency metadata, and ordered task listing.
