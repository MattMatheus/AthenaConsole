# Story: Implement Evidence Collection Hooks

**As a Persona Developer, I want a way for agents to attach proof of their work so that their results are verifiable.**

## Problem Statement
We need to move from "Agent Says" to "Agent Proves." We need a standard hook for agents to upload logs, test results, or screenshots as evidence.

## Acceptance Criteria
- PDK includes `runtime.attachEvidence(label, content, type)`.
- Support for `text`, `json`, and `binary` evidence types.
- The control plane validates that evidence is only attached to active runs.
- Every evidence piece is assigned a unique ID and timestamp.

## Technical Constraints
- Evidence submission must be asynchronous to the main turn to prevent latency.
