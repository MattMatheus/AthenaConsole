# Story: Create Symbolic Navigation Tools for Agents

**As an Agent, I want tools like 'get_definition' and 'find_references' so that I can navigate code semantically.**

## Problem Statement
Agents spend too many turns "guessing" where a function is defined. By providing symbolic tools, we reduce turn counts and improve the accuracy of the agent's reasoning.

## Acceptance Criteria
- New tools added to the standard agent toolset:
    - `athena_lsp_definition`: Returns the location and signature of a symbol.
    - `athena_lsp_references`: Returns a list of all callers/usages.
    - `athena_lsp_symbols`: Returns all symbols defined in a file.
- Tools are automatically available to all personas with the `code-analysis` skill.
- Tool outputs are formatted to be token-efficient (e.g., returning only the relevant code snippet).

## Technical Constraints
- Must handle cases where the LSP is not available (graceful fallback to `grep`).
