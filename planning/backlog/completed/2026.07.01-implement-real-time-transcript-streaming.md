# Story: Real-time Transcript Streaming

**As a Developer, I want to see my agent's reasoning in real-time so that I can debug its thought process live.**

## Problem Statement
Waiting for a run to finish before seeing the results makes debugging slow. Real-time streaming allows developers to see immediately when an agent goes off-track.

## Acceptance Criteria
- `SessionService` supports streaming updates via WebSockets or SSE.
- Every new `TranscriptEntry` is broadcast to connected clients for that session.
- Frontend component renders the incoming stream with clear role differentiation (System, User, Assistant, Tool).
- Supports "Reconnection" logic to ensure the stream remains active during network blips.

## Technical Constraints
- Ensure that streaming doesn't impact the performance of the LLM turn.
- Security check: Users can only stream sessions they have permission to view.
