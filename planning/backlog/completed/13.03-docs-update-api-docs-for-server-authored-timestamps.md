# Story: [Docs] Update API Docs for Server-Authored Timestamps

**As a developer, I need the API documentation updated to clearly state that policy timestamps are server-authored, so that API consumers understand the contract.**

## Acceptance Criteria
*   The documentation for the policy update/create API endpoints is updated.
*   The `updatedAt` field in the request body schema is marked as `readOnly`.
*   A note is added explaining that the field is server-authored and any client-provided value is ignored.
