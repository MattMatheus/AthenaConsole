# Story: Implement A2A Message Flow Visualization API

**As a Workflow Architect, I want to see the graph of agent interactions so that I can troubleshoot multi-agent communication.**

## Problem Statement
When multiple agents work together (A calls B who calls C), it becomes difficult to trace a single request through the system. We need an API that can reconstruct this interaction graph.

## Acceptance Criteria
- `EventService` updated to correlate messages using `parentRunId` or `traceId`.
- `GET /api/v1/work/flows/:traceId` returns a graph-structured JSON (nodes and edges).
- Nodes represent agents/personas; edges represent messages or tool calls.
- Includes status for every hop (e.g., "Step 2: Message Sent", "Step 3: Response Failed").

## Technical Constraints
- Must be able to traverse the event log efficiently using indexed trace IDs.
