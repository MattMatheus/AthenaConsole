# Epic: Distributed Locking Backends

**As a Platform Engineer, I want Athena to support Redis and K8s Leases so that I can run the orchestrator in a high-availability cluster.**

## Problem Statement
The current locking mechanism only works within a single process (LocalMemoryLock). In a distributed deployment, multiple Athena instances might simultaneously trigger runs, violating concurrency policies and over-consuming LLM budgets.

## Success Metrics
- **Redis Provider:** Production-ready implementation using `ioredis`.
- **K8s Lease Provider:** Native K8s implementation for cloud-native environments.
- **Concurrency Integrity:** Proof that `maxConcurrentRuns` is respected even when runs are triggered across three different Athena nodes.

- `21.01-implement-redis-distributed-lock-provider`
- `21.02-implement-k8s-lease-distributed-lock-provider`
- `21.03-integration-test-distributed-lock-contention`
