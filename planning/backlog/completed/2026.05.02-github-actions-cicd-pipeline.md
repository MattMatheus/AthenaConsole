# M5.02: Implement GitHub Actions CI/CD Pipeline

**As a Platform Engineer, I want to automate the build and deployment of Project Athena via GitHub Actions, so that every change is verified and deployed without manual intervention.**

### Problem Statement
Manual deployments are error-prone and slow down the feedback loop. We need a standardized pipeline to build our containerized components and deploy them to Azure.

### User Persona
- **Alex (Platform Engineer):** Needs a "push-to-deploy" workflow that handles containerization and cloud synchronization.

### Acceptance Criteria
- [ ] GitHub Action workflow created in `.github/workflows/deploy-control-plane.yml`:
    - Builds the Docker image for the API/Runner.
    - Pushes the image to Azure Container Registry (ACR).
    - Deploys the image to AKS using `kubectl` or Helm.
- [ ] GitHub Action workflow created in `.github/workflows/deploy-console.yml`:
    - Builds the React console.
    - Deploys the build artifacts to Azure Static Web Apps.
- [ ] Secrets (ACR credentials, Kubeconfig) are managed securely via GitHub Actions Secrets.
- [ ] The pipeline includes a "smoke test" step to verify the API is reachable after deployment.

### Risks & Assumptions
- **Assumption:** The repository is hosted on GitHub.
- **Risk:** Build times for Docker images may consume GitHub Action minutes; caching strategies should be considered.
