# M3.02: Create a Unified Local Stack Definition

**As a New Developer, I want a single command to bring up the entire local development stack (API, Console) so I can get started in minutes.**

### Problem Statement
The current `docker-compose.yml` may contain configurations intended for production or complex cloud-integrated setups. A new developer needs a single, simple file that orchestrates only the components required for a pure local development workflow.

### User Persona
- **New Contributor:** Wants to avoid system administration and focus on writing persona code.

### Acceptance Criteria
- [ ] A new `docker-compose.local.yml` file is created at the repository root.
- [ ] This file defines, at minimum, the `api` and `console` services required to run the local stack.
- [ ] It is optimized for local development (e.g., mounts source code directories, uses local-first configurations).
- [ ] Any services not required for the core local loop (e.g., production-specific monitoring tools) are removed.
- [ ] The new quickstart guide references this file as the primary way to start the local environment.

### Risks & Assumptions
- **Risk:** The `docker-compose.local.yml` could drift out of sync with the base `docker-compose.yml`. This needs to be mentioned as a maintenance task in developer docs.
