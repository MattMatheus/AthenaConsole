# Story: Implement K8s CPU and Memory Metrics

**As a developer, I want the `K8sMetricsProvider` to query the Kubernetes Metrics Server so that it can populate the `cpuUsage` and `memoryUsage` fields in the `FleetSummary` with real data from the cluster.**

## Acceptance Criteria
*   The provider makes a second API call to the K8s Metrics API (`/apis/metrics.k8s.io/v1beta1`) to get pod metrics.
*   The CPU (cores) and Memory (bytes) usage for all agent pods are summed and added to the `FleetSummary` object.
*   The feature is degradeable; if the Metrics Server is not available, the rest of the summary is still returned, and CPU/Memory fields are null.
*   Tests are added to validate the aggregation logic with mock metrics data.
