# Story: [Docs] Document runId APIs and Migration Path

**As a developer, I need clear documentation for the new `runId`, the new run-scoped APIs, and the migration path, so that API consumers can update their clients.**

## Acceptance Criteria
*   The API documentation is updated to include the new `runId` field in all relevant data models.
*   The new run-scoped API endpoints are fully documented.
*   A new "Migration Guide" section is added to the documentation, explaining how to move from the old session-scoped APIs to the new run-scoped APIs, with clear examples.
*   The old endpoints are marked as 'deprecated' in the documentation.
