# Story: Implement Unified Startup and Dev Proxy

**As a Developer, I want a single command to start the entire Project Athena solution so that I can develop and test the end-to-end experience with minimal friction.**

## Problem Statement
Currently, the backend and frontend must be started in separate terminals with manual environment configuration. This is error-prone and increases the barrier to entry for new contributors. We need a unified "developer mode" that handles process orchestration and API proxying out of the box.

## Acceptance Criteria
- Implement a root-level `npm run dev` command that:
    - Starts the backend API server (e.g., via `tsx watch src/index.ts`).
    - Starts the frontend Vite development server.
    - Manages both processes concurrently (e.g., using `concurrently` or similar).
- Configure **Vite Proxy** in the frontend:
    - Ensure all requests to `/api/*` are automatically proxied to the backend API port (default `3000`).
    - Handle Webhook/WebSocket proxying if required for future real-time streaming features.
- Provide a clear, unified log output in the terminal with prefixing for `[api]` and `[ui]`.
- Add a "System Check" on startup to verify required environment variables (`.env`) are present.

## Technical Constraints
- Must work across macOS, Linux, and Windows (via WSL/CMD/PowerShell).
- Ensure that killing the root `npm run dev` process correctly terminates both child processes.
- Do not hardcode ports; use environment variable fallbacks for both frontend and backend.
