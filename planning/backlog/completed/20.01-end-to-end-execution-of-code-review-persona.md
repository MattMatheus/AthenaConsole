# Story: End-to-End Execution of Code-Review Persona

**As a Platform Operator, I want to run a real code review on Athena itself so that I can verify the system is ready for real-world usage.**

## Problem Statement
We have verified that the individual pipes (Git, Model, Context) work, but we have not yet run a complete cycle that involves multi-file context assembly, complex diffing, and real-world model reasoning.

## Acceptance Criteria
- Successfully execute: `athena persona run --name code-review --repo . --head main --base main~1`.
- The run uses a real LLM (configured via Epic 19).
- The CLI provides real-time feedback (or at least a clear "running" state).
- The run completes with `status: ok`.
- Errors in the Git diff or Model execution are captured and reported without crashing the CLI.

## Technical Constraints (For Developer)
- Ensure the `code-review` persona configuration in `personas/code-review.json` is correctly tuned for the current repo size.
- Verify that `main~1` (or a similar relative ref) is correctly resolved by the Git service.
