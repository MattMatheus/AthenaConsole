# Research: Rejection Event Storage Strategy

**As a developer, I need to research and recommend a strategy for storing `RunRejectionEvent`s so that we can choose a scalable and queryable solution that fits our architecture.**

## Scope
*   Investigate at least two options for storing events (e.g., dedicated log stream vs. new database table vs. in-memory cache).
*   Compare the options based on:
    *   Query performance and flexibility.
    *   Scalability and operational overhead.
    *   Ease of implementation within the current stack.
    *   Data retention and durability.
*   The deliverable is a short document or markdown file with a clear recommendation and justification.
