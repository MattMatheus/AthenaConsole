# Epic: Persistent Event & Audit Logs

**As an Auditor, I want run rejections and lifecycle events to be stored persistently so that I can perform post-mortem analysis of failures.**

## Problem Statement
Telemetry and rejection events are currently stored in volatile memory. If an Athena node crashes or is restarted during a scaling event, all audit records for that period are lost.

## Success Metrics
- **Durability:** Events survive a process restart.
- **Performance:** Appending events does not block the "hot path" of run execution.
- **Queryability:** The API can return historical rejections from 24+ hours ago.

## Included Stories (Proposed)
- `23.01-implement-persistent-file-based-event-store`
- `23.02-migrate-rejection-store-to-persistent-backend`
- `23.03-implement-event-retention-and-pruning-logic`
