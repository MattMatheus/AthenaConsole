# Story: [Backend] Add Health Metrics to Fleet API

**As a backend developer, I need to extend the `FleetSummary` API to include uptime and error rate metrics so that the Fleet Dashboard can display them.**

## Acceptance Criteria
*   The `FleetSummary` contract in `api-contracts.ts` is updated with optional `uptime` and `errorRate` fields.
*   The metrics provider interface (`IFleetMetricsProvider`) is updated.
*   The `local` and `k8s` provider implementations are updated to calculate and return this data. This might involve reading from run history or other state stores.
*   Once implemented, a new frontend story will be needed to display this data.
