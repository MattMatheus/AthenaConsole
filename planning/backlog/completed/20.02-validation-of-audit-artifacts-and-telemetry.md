# Story: Validation of Audit Artifacts and Telemetry

**As an Auditor, I want to see a complete record of every persona run so that I can verify the agent's work and track costs.**

## Problem Statement
A successful run is only half the battle. We must ensure the resulting artifacts (`result.json`, `report.md`) are persisted correctly and contain all the telemetry needed for fleet management.

## Acceptance Criteria
- After a persona run, the `.athena/persona-runs/` directory contains a uniquely named folder for the run.
- `result.json` exists and contains:
    - `usage` statistics (tokens).
    - `findings` (priority, file, line, message).
    - `runtimeResult` metadata (which model/provider was actually used).
    - `contextMeta` (how much context was sent).
- `report.md` exists and is valid Markdown.
- The `eventService` correctly records the `persona:run` lifecycle events in the central event log.

## Technical Constraints (For Developer)
- Use the `PersonaStore` to verify path resolution.
- Verify that the `FileStateStore` is correctly persisting these records and not leaving stale `.tmp` files.
