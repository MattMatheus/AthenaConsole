# M3.03: Write the "3-Minute Quickstart" Guide

**As a New Developer, I want a simple, top-level `GETTING_STARTED.md` that gets me from a `git clone` to running my first agent in minutes.**

### Problem Statement
Developer onboarding documentation is currently spread across multiple files in the `planning/` directory and is focused on project contributors, not just users. We need a single, highly visible document that is ruthlessly focused on the fastest possible path to a successful local run.

### User Persona
- **New Contributor / External Developer:** Wants to try the project with minimal friction.

### Acceptance Criteria
- [ ] A new `GETTING_STARTED.md` file is created at the repository root.
- [ ] The guide contains simple, numbered steps:
    1.  Prerequisites (Install Podman/Docker, Node.js).
    2.  Clone the repository.
    3.  Set up the `.env` file (copy from example, add LLM API key).
    4.  Run `podman compose -f docker-compose.local.yml up --build`.
    5.  Execute a sample `athena persona run` command.
- [ ] The guide explicitly states that the Terraform/Azure setup is for production deployments and is **not** required for local development.
- [ ] The root `README.md` is updated to link prominently to this new guide.

### Risks & Assumptions
- **Assumption:** Users are familiar with using an `.env` file for API keys.
