# Story: Implement RBAC Role and Permission Management UI

**As a Security Admin, I want to manage user permissions via a UI so that I can easily audit and control platform access.**

## Problem Statement
Managing RBAC roles and user assignments via config files or API calls is slow and lacks visibility. For security compliance, we need a clear visual record of who has what access.

## Acceptance Criteria
- UI to list all defined Roles and their associated Permission strings.
- UI to assign/remove Roles from Identity headers or service tokens.
- "Permission Audit" view: Select a user and see exactly which resources they can access.
- Changes are immediately recorded in the persistent audit log.

## Technical Constraints
- Use the `IdentityService` as the source of truth.
- Ensure the UI itself is protected by a "Bootstrap Admin" or specific high-level role.
