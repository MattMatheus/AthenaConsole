# Story: Implement Redis Distributed Lock Provider

**As a Platform Engineer, I want to use Redis for distributed locking so that I can run Athena in a multi-node cluster.**

## Problem Statement
The current locking is limited to a single process. In a high-availability deployment, we need a shared locking backend to enforce global concurrency policies.

## Acceptance Criteria
- New `RedisLockProvider` implemented in `src/control-plane/distributed-lock.ts`.
- Uses `ioredis` to manage keys with `NX` (not exists) and `PX` (expiry) flags.
- Lock keys follow the pattern `athena:lock:<name>`.
- Configurable via `ATHENA_REDIS_URL`.
- Provides graceful handling of Redis connection failures (fail-closed by default).

## Technical Constraints
- Must implement the `IDistributedLock` interface.
- Must ensure that the `ownerId` is verified during release to prevent one node from releasing another's lock.
