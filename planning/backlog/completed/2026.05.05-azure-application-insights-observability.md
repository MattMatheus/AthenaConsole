# M5.05: Integrate Azure Application Insights

**As a Platform Operator, I want to integrate Azure Application Insights, so that I have full visibility into the performance and health of the distributed orchestration plane.**

### Problem Statement
In a distributed environment, logs alone are insufficient for debugging. We need distributed tracing to follow a request from the Console through the API and into the Persona Execution environment.

### User Persona
- **Alex (Platform Engineer):** Needs to monitor latency, error rates, and dependencies (Redis, OpenAI) in real-time.

### Acceptance Criteria
- [ ] Application Insights SDK integrated into the Node.js Control Plane.
- [ ] Telemetry correlation enabled (traceparent/tracestate) across API calls.
- [ ] Custom dimensions added for `runId`, `personaId`, and `tenantId` to allow for deep-dive filtering.
- [ ] Azure Monitor Dashboard created to visualize:
    - Request volume and failure rate.
    - P95 latency for AI model responses.
    - Redis lock acquisition timing.

### Risks & Assumptions
- **Risk:** High volume of telemetry can consume significant credits; sampling should be configured for non-critical events.
- **Assumption:** The application is already using a compatible logging framework (e.g., Pino or Winston).
