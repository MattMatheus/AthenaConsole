# Story: Event Retention and Pruning Logic

**As a Platform Admin, I want to limit the size of my event logs so that they don't consume all available disk space.**

## Problem Statement
A busy Athena cluster will generate gigabytes of events. We need an automated way to prune old data based on age or size.

## Acceptance Criteria
- Automated "Sweep" logic added to `LocalEventService`.
- Prunes events older than `ATHENA_EVENT_RETENTION_DAYS` (default 30).
- Supports a `ATHENA_EVENT_MAX_BYTES` limit to cap total disk usage.
- Pruning activity is itself logged as an event.

## Technical Constraints
- Pruning must be "non-blocking" to the main event emission path.
- Use a temporary file during pruning to ensure no data loss if the process is interrupted.
