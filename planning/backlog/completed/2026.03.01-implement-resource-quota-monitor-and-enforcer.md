# Story: Implement Resource Quota Monitor and Enforcer

**As a Platform Admin, I want runs terminated when they exceed resource quotas so that runaway workloads fail closed.**

## Problem Statement
Container isolation improves blast-radius control, but we still need active quota enforcement for CPU, memory, and disk to prevent infrastructure exhaustion.

## Acceptance Criteria
- Add a resource quota monitor for sandbox-backed runs (Docker and K8s paths).
- Enforce fail-closed termination when configured CPU/memory/disk limits are exceeded.
- Expose quota decisions through existing control-plane event semantics.
- Preserve policy-aware fallback and required-sandbox fail-closed behavior.
- Add deterministic tests for enforcement and safe cleanup on quota-triggered termination.

## Technical Constraints
- Keep enforcement behind control-plane/backend boundaries.
- Preserve lock-guarded state transitions and state-store invariants.
- Keep contract/schema changes additive and backward-compatible.
