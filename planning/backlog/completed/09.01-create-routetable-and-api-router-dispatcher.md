# Story: Create RouteTable and API Router Dispatcher

**As a backend developer, I need to create a generic `APIRouter` class and `RouteTable` data structure to replace the monolithic request routing logic.**

## Acceptance Criteria
*   A new `APIRouter` class is created. It is initialized with a `RouteTable`.
*   The `RouteTable` is an array of route definitions, where each definition includes an HTTP method, a path pattern (e.g., `/api/v1/personas/:id`), and a handler function.
*   The `APIRouter` has a `dispatch` method that takes a request and finds the appropriate handler in the route table to execute.
*   The router supports basic path parameters (e.g., `:id`).
