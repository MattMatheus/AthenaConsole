# Story: Provider Configuration and .env Template

**As a New User, I want a clear configuration template so that I can set up my LLM providers quickly.**

## Problem Statement
There is currently no `.env.example` file, and new users have to guess which environment variables are required to enable specific providers.

## Acceptance Criteria
- A `.env.example` file is created in the project root.
- Includes placeholders and comments for:
    - `ATHENA_DEFAULT_PROVIDER`
    - `ATHENA_DEFAULT_MODEL`
    - `ATHENA_OPENAI_API_KEY`
    - `ATHENA_OPENAI_BASE_URL`
- Documentation in `docs/user/02-installation.md` is updated to include a "Configuration" section.
- `src/shared/config.ts` is verified to support the new `ATHENA_OPENAI_*` variables.

## Technical Constraints (For Developer)
- Do not commit a real `.env` file.
- Ensure `loadConfig` provides sensible defaults if variables are missing.
