# Story: Implement Local Memory Lock Provider

**As a developer, I want a simple, in-memory implementation of the `IDistributedLock` interface so that I have a baseline for local development and for testing the locking workflow without external dependencies.**

## Acceptance Criteria
*   A `LocalMemoryLock` class is created that implements `IDistributedLock`.
*   It uses an in-memory object to track active locks.
*   It is functionally equivalent to the existing (non-distributed) concurrency check but fits the new interface.
*   Unit tests are created to verify its acquire/release logic.
