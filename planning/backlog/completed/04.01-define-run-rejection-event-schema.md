# Story: Define Run Rejection Event Schema

**As a developer, I need a clear, versioned schema for the `RunRejectionEvent` so that we have a consistent, structured way to record why a run was not scheduled.**

## Acceptance Criteria
*   A `RunRejectionEvent` interface is defined in `src/control-plane/api-contracts.ts`.
*   The schema includes: `timestamp`, `policyType` (e.g., 'CONCURRENCY'), `limit`, `rejectedRunDetails` (e.g., persona name).
*   The schema is versioned and documented.
