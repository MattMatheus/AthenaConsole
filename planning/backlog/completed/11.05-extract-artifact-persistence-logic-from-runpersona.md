# Story: Extract 'Artifact Persistence' Logic from runPersona

**As a backend developer, I need to extract the artifact persistence logic from `runPersona` into a new, dedicated function.**

## Acceptance Criteria
*   A new function (e.g., `persistArtifacts`) is created.
*   It is responsible for taking the final output and saving any required artifacts to the filesystem or other storage.
*   `runPersona` is updated to call this new function at the end of the workflow.
*   The artifact persistence logic is covered by new unit tests, likely using a mocked filesystem.
