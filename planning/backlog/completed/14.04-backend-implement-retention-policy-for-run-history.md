# Story: [Backend] Implement Retention Policy for Run History

**As a platform maintainer, I want a configurable retention policy for run history so that we can manage storage costs and data growth predictably.**

## Acceptance Criteria
*   A configuration option is added to set the retention period for run history (e.g., `RUN_HISTORY_RETENTION_DAYS=30`).
*   A background job or other mechanism is implemented to periodically delete run history records older than the configured retention period.
*   The deletion logic is efficient and does not impact API performance.
*   The new configuration is documented for operators.
