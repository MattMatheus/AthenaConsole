# Epic: Self-Review Milestone

**As a Product Manager, I want Athena to perform a "Self-Review" so that we can verify the end-to-end stability and value of the platform.**

## Problem Statement
We have high unit test coverage, but we have not yet executed a complex, real-world task. Running a code review on Athena's own repository is the ultimate "eat your own dog food" test for the Git integration, context assembly, and model orchestration logic.

## User Personas
- **Product Manager:** Needs to verify the system delivers the promised value.
- **Sam (Operator):** Needs to see audit artifacts (JSON/Markdown) generated correctly.

## Success Metrics
- **End-to-End Success:** `athena persona run --name code-review` completes with `status: ok`.
- **Artifact Integrity:** `result.json` contains valid findings and `report.md` is a human-readable summary of the project's own code.
- **Context Verification:** Evidence that the system correctly assembled diffs, dependencies, and referenced file snapshots.

## Included Stories (Proposed)
- `20.01-execute-athena-self-review-integration-test`
- `20.02-verify-persona-run-artifact-persistence-and-formatting`
