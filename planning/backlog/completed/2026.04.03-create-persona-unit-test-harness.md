# Story: Create Persona Unit Test Harness with MockRuntime

**As a Developer, I want to unit test my persona logic without spending API credits or waiting for a real LLM.**

## Problem Statement
Testing a persona currently requires a full end-to-end run. This is slow and expensive. We need a way to verify the "assembly" phase (context gathering, prompt building) and the "parsing" phase (JSON repair, finding extraction) in isolation.

## Acceptance Criteria
- `PersonaTestHarness` provided in the PDK.
- Includes `MockRuntime` which takes a predefined map of `Input -> Output`.
- Ability to assert on:
    - Which files were included in the context pack.
    - The final constructed prompt string.
    - Whether the persona correctly parsed a specific mock LLM response.
- Integration with `vitest` or `jest` for automated CI testing.

## Technical Constraints
- Mocking must be "deep" enough to simulate the FileStateStore and Git services.
