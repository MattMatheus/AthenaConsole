# Epic: Local Agent Catalog

## Status

Refinement.

## Goal

Make formal agents visible and understandable in the console after local plugins are indexed.

## Source Decisions

- `docs/product/architecture/decisions/0007-agent-manifest-and-lifecycle-contract.md`
- `docs/product/architecture/decisions/0008-plugin-package-format.md`
- `docs/product/architecture/decisions/0010-sqlite-app-state-architecture.md`

## Candidate Stories

### 2026.11.01 Add Agent Catalog API

Expose indexed plugins and agents through API/service methods suitable for the console.

Acceptance criteria:

- Lists enabled plugin agents.
- Filters by capability.
- Returns manifest-derived metadata.
- Exposes validation/load errors for plugins and agents.

### 2026.11.02 Build Agent Catalog Page

Create the console page for browsing installed agents.

Acceptance criteria:

- Shows system and workspace plugins.
- Shows agent name, version, capabilities, implementation type, observability mode, and safety limits.
- Supports empty, loading, error, and validation-warning states.

### 2026.11.03 Build Agent Detail Page

Create an agent detail view for operator inspection.

Acceptance criteria:

- Renders declared inputs and output/artifact hints.
- Renders permissions and risk classes.
- Renders supported backend/implementation information.
- Links back to source plugin metadata.

## Non-Goals

- No task creation flow.
- No plugin registry.
- No remote installation.
