# Epic 2026.27: Model Provider And Secrets Setup

## Status

Complete.

## Goal

Give operators a clear, safe way to connect AI model providers and verify that agents can use them.

## Problem

Operators can see manifest-backed agents, but the console does not yet answer the next practical question: how does an agent get an AI model, API key, endpoint, or subscription-backed runtime?

## Why Now

Real work requires an AI provider path. Without provider setup, agent definitions are visible but not sufficiently actionable.

## Scope

In scope:

- Provider settings surface for API-key-backed providers.
- Initial support for OpenAI-compatible provider configuration, including provider name, base URL when relevant, model, and API key reference.
- Secret storage model appropriate for local and local-server deployments.
- Redaction rules for logs, events, diagnostics, and artifacts.
- Test-connection flow and provider readiness diagnostics.
- Agent/workflow UI that shows required provider configuration before run.
- Research note for whether subscription-backed tools such as Codex can be used through a supported integration path.

Out of scope:

- Unsupported scraping or reuse of consumer app sessions.
- Enterprise SSO.
- Team-wide secret sharing.
- Hosted key vault integration unless selected in a later deployment epic.

## Constraints

- Do not store raw secrets in ordinary app-state records.
- Never echo secrets into logs, events, artifacts, or browser-visible diagnostics.
- Keep provider configuration explicit enough for local-server deployment.

## Risks

- Secret storage can become insecure if treated like normal app-state.
- Provider support can sprawl unless the first implementation is deliberately narrow.
- Codex subscription integration may not have a supported product/API path and should not be promised until researched.

## Validation Expectations

- Architecture review for secrets before implementation.
- Unit tests for redaction and provider validation.
- Console browser QA for setup and missing-provider states.
- Manual smoke with a test provider configuration that does not leak secret values.
