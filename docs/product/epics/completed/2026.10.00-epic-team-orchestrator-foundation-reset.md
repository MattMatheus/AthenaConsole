## Candidate Stories

### 2026.10.01 Accept Reset ADR Set

Review ADRs 0007 through 0014, resolve open questions, and move accepted decisions to an implementation-ready status.

Acceptance criteria:

- Each ADR has status updated to accepted or explicitly deferred. Completed for ADRs 0007 through 0014.
- Remaining open questions are resolved during story breakdown or converted into follow-up research items.
- Architecture README reflects the final accepted/deferred set. Completed for ADRs 0007 through 0014.

### 2026.10.02 Choose SQLite Library and Migration Pattern

Select the TypeScript SQLite library, migration format, database file location, and test strategy.

Acceptance criteria:

- ADR 0010 open questions are resolved.
- A migration strategy is documented.
- Initial database test strategy is documented.

Promoted active story:

- `flywheel/backlog/engineering/active/2026.10.01-implement-sqlite-app-state-foundation.md`

### 2026.10.03 Define Initial Manifest Schemas

Draft the first plugin, agent, workflow template, task input, artifact, and event schemas.

Acceptance criteria:

- Schema files exist under a proposed canonical path.
- Example manifests validate against schemas.
- Schema ownership and versioning rules are documented.

Promoted active story:

- `flywheel/backlog/engineering/active/2026.10.02-define-plugin-and-agent-manifest-schemas.md`

### 2026.10.04 Map Legacy Concepts to Reset Domain

Map current personas, sessions, runs, fleet dashboard concepts, evidence, and scheduling pieces to the reset model.

Acceptance criteria:

- Legacy-to-reset mapping document exists.
- Keep, rewrite, archive, and delete recommendations are explicit.
- Migration risks are listed.

### 2026.10.05 Plan First Console Slice

Define the smallest useful console flow for local manual task creation and run inspection.

Acceptance criteria:

- User flow is documented.
- Required screens/components are listed.
- Required backend/API surfaces are listed.
- Non-goals are explicit.

## Non-Goals

- Do not implement the new database layer in this epic.
- Do not create active implementation stories until ADR review is complete.
- Do not revive enterprise fleet governance as a near-term product center.

## PM Notes

This epic produced the first active implementation sequence. Later candidate stories remain refinement material until the first foundation reset track lands.
