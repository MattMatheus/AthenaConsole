# Epic: Task Workbench

## Status

Refinement.

## Goal

Let a solo operator create manual tasks, assign compatible agents, run tasks locally, and inspect outputs.

## Candidate Stories

### 2026.12.01 Add Task APIs

Expose task CRUD, assignment, and status transitions for the console.

Acceptance criteria:

- Creates draft tasks.
- Assigns compatible agents.
- Validates `ready` status requires assigned agent.
- Lists tasks by status.

### 2026.12.02 Build Manual Task Create Flow

Create a console flow for manually creating a task.

Acceptance criteria:

- Operator enters title, description, and task inputs.
- Operator selects a compatible agent.
- Inputs are rendered from the agent manifest.
- Task can be saved as draft or ready.

### 2026.12.03 Implement Local Process Task Runs

Run assigned task agents through the local-process backend.

Acceptance criteria:

- Validates inputs before run.
- Records run and events.
- Captures final output and artifact metadata.
- Supports cancellation.

### 2026.12.04 Build Run Inspection View

Create the console run view.

Acceptance criteria:

- Shows timeline events.
- Shows logs and artifacts.
- Shows final output.
- Shows stopped-by-limit and approval-waiting states.

## Non-Goals

- No mission DAG execution.
- No schedule UI.
- No remote hosted execution.
