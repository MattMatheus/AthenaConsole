# Story: Symbol Signature Context Compaction Strategy

**As a Platform Operator, I want to include symbol signatures in context instead of full files to save tokens and improve focus.**

## Problem Statement
When an agent reads a file, we often send the whole file, including irrelevant implementation details. For many tasks, the agent only needs the "signatures" (interfaces, function headers) of the symbols it is interacting with.

## Acceptance Criteria
- New `ContextStrategy` called `symbolic-signatures`.
- When active, the orchestrator uses the LSP to extract only the signatures of symbols in the requested file.
- Replaces the full file content in the context pack with the compacted signature list.
- Significant reduction in token count (Target: 50%+) for large dependency files.

## Technical Constraints
- Must ensure that the signatures provide enough information for the LLM to understand the "API" of the file.
