# Story: Global Session Search and Indexing

**As an Operator, I want to search through historical sessions so that I can find past solutions and audit agent behavior.**

## Problem Statement
As the number of sessions grows into the thousands, finding a specific past interaction becomes a needle-in-a-haystack problem.

## Acceptance Criteria
- Search interface in the Session Explorer.
- Full-text search across all transcripts.
- Filters:
    - `personaId`
    - `dateRange`
    - `status` (ok/failed)
    - `userId`
- Results show "context snippets" highlighting the search term.
- Performance: Search returns results in < 2 seconds for up to 10k sessions.

## Technical Constraints
- Consider using a lightweight search index (e.g., `flexsearch` or a dedicated SQLite FTS table).
- Must respect RBAC: Users only see search results for sessions they have permission to view.
