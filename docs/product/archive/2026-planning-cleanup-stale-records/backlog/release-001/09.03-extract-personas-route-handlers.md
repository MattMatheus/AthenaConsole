# Story: Extract 'Personas' Route Handlers

**As a backend developer, I need to extract the API logic for the 'personas' route family out of the monolithic router and into its own handler file, using the new `APIRouter`.**

## Acceptance Criteria
*   A new file (e.g., `src/api/routes/persona-routes.ts`) is created.
*   All logic for handling persona-related API endpoints is moved into handler functions in this new file.
*   These handlers are registered in the application's main `RouteTable`.
*   The old logic is removed from the original monolithic function.
*   Existing API tests for these endpoints continue to pass.
