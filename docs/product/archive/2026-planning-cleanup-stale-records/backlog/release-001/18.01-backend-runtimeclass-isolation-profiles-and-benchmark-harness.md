# Story: [Backend] Add RuntimeClass Isolation Profiles and Benchmark Harness

**As a platform maintainer, I need runtime isolation profiles and benchmark telemetry so we can choose secure runtime defaults using Athena-specific performance and reliability data.**

## Scope
* Add config surface for sandbox/runtimeClass selection by profile (`standard`, `high-security`).
* Emit runtime class and startup mode telemetry (`warm` vs `cold`).
* Add a deterministic benchmark harness/test fixture for comparative runtime measurements.
* Preserve backward compatibility when runtimeClass is unset.

## Acceptance Criteria
* Config supports runtime isolation profile selection with backward-compatible defaults.
* High-security profile supports fail-closed behavior when sandbox runtime requirements are unmet.
* Telemetry includes runtime class, start mode, and latency outcomes needed for benchmark analysis.
* Benchmark harness can run repeatable scenario matrix across configured runtime classes.
