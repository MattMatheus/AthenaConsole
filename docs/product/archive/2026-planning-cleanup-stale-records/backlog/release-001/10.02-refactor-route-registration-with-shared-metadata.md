# Story: Refactor Route Registration with Shared Metadata

**As a backend developer, I need to establish a clear, metadata-driven pattern for how route families register their endpoints, to ensure consistency and reduce boilerplate.**

## Acceptance Criteria
*   A shared `RouteDefinition` interface or type is used across all route handler files.
*   Each route module (e.g., `persona-routes.ts`) exports its routes as a collection of `RouteDefinition` objects.
*   The main application entry point dynamically collects these exported routes to build the global `RouteTable`.
*   The pattern is documented for future developers.
