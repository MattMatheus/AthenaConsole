# Story: Create K8s Metrics Provider Class

**As a developer, I want to create a new `K8sMetricsProvider` class that implements the standard fleet metrics provider interface so that it can be used as a backend for the fleet summary API.**

## Acceptance Criteria
*   A new file `src/control-plane/backends/k8s-metrics-provider.ts` is created.
*   The `K8sMetricsProvider` class is defined and implements the `IFleetMetricsProvider` interface (assuming name from story 01).
*   The new provider is registered in the backend factory or service locator, allowing it to be selected as the active provider via configuration.
*   The initial implementation can use stubbed or placeholder data.
