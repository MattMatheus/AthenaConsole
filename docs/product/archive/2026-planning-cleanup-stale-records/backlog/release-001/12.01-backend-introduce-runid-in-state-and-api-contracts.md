# Story: [Backend] Introduce runId in State and API Contracts

**As a backend developer, I need to introduce a unique `runId` at the point of run creation and include it in all relevant state and API objects.**

## Acceptance Criteria
*   A unique `runId` (e.g., a UUID) is generated every time a new run is initiated.
*   The `runId` is added as a field to the core run state objects in memory and/or the database.
*   The `runId` is added to all relevant API contracts, such as the objects returned by active-run and run-history endpoints.
*   Existing tests are updated to reflect the presence of the new `runId`.
