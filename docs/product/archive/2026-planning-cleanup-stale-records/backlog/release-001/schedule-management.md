# Feature: Schedule Management

## User Stories

*   **As an admin/operator, I want to see a list of all scheduled tasks, their frequency, and their last run status so that I can have an overview of all automated processes.**
*   **As an admin/operator, I want to create, edit, and disable scheduled tasks through a user-friendly interface so that I can easily manage the automation of agent tasks.**
*   **As an admin/operator, I want to view the run history and logs for each scheduled task so that I can troubleshoot failures and monitor their performance.**
