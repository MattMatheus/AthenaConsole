## User Story

As a Team Orchestrator operator, I need an agent detail page so I can inspect a specific agent's manifest contract before assigning work to it.

## Scope

Create a detail view reachable from the agent catalog page for operator inspection.

## Acceptance Criteria

- Renders declared inputs and output/artifact hints.
- Renders permissions and risk-relevant safety classes.
- Renders runtime backend, implementation type, observability mode, and safety limits.
- Links back to source plugin metadata.
- Preserves catalog filtering/navigation ergonomics when returning to the catalog.
- Supports loading, missing/not-found, and API error states.

## Non-Goals

- No task creation flow.
- No plugin install/registry flow.
- No agent execution changes.
- No manifest editing.

## Validation Expectations

- Inspect the existing agent catalog page implementation first.
- Run the narrowest meaningful console UI validation.
- Use browser verification for the detail navigation and responsive layout.

## Engineering Handoff

Implemented the agent detail page and catalog-to-detail navigation.

Delivered:

- Added `/agents/:agentId` detail route.
- Linked catalog agent rows to the detail route with version and current catalog filters preserved in URL search params.
- Moved catalog filters into URL search params so returning from detail preserves search, source, state, and capability filters.
- Extended console catalog parsing to retain manifest `inputs`, `outputs`, and `runtime` metadata from the catalog API.
- Rendered agent runtime/implementation/observability/limit metadata.
- Rendered declared input fields and output/artifact hints.
- Rendered permission metadata plus derived risk labels such as `network-read`, `local-write`, `shell-command`, and manifest approval classes.
- Rendered source plugin metadata, source state, package path, status, and enablement.
- Added loading, API error, and not-found states.
- Verified detail navigation, back-to-catalog filter preservation, and not-found behavior in the in-app browser.
