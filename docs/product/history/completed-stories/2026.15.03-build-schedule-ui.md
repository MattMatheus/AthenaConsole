## User Story

As a Team Orchestrator operator, I need to view and manage task schedules in the console so I can pause, resume, run, and remove repeatable local work without using raw API calls.

## Scope

Build the first console schedule management surface for SQLite task-target schedules and the existing schedule API.

## Acceptance Criteria

- Adds a console route for schedule management.
- Lists schedules with name/id, target task, status, next run, last run, timezone, and recurrence/one-shot details.
- Provides pause/resume, run now, and delete actions.
- Provides a task-schedule creation flow for one-shot `runAt` schedules and simple recurring schedules that compile to RRULE.
- Uses existing task APIs to choose ready task targets.
- Shows due-run results from the schedule tick/run endpoints, including missed/skipped/failure details currently returned by the API.
- Links last task run ids to the existing run inspection view when available.
- Keeps the UI consistent with existing console task/run surfaces and uses focused, work-oriented controls.
- Includes focused console tests for schedule list formatting, form parsing/RRULE generation, action state changes, and failure rendering.

## Non-Goals

- No always-on background worker UI.
- No hosted scheduler controls.
- No mission or workflow-template scheduling UI.
- No advanced RRULE editor beyond simple presets.
- No full schedule history table unless already exposed by the existing API.

## Engineering Handoff

Completed.

Implemented the first console schedule management surface.

Delivered surfaces:

- Added `/schedules` console route and primary navigation entry.
- Added `features/schedules` API bindings, React Query mutations, DTO parsing, and model helpers.
- Lists schedule name/id, task target, status, cadence, next run, timezone, last run, and updated timestamp.
- Links `lastRunId` to the existing task run inspection view.
- Supports pause/resume, run now, delete, refresh, and tick-due actions.
- Adds a task schedule creation form for one-shot `runAt` schedules and simple hourly/daily/weekly RRULE schedules.
- Uses the existing task list API to populate ready task targets while preserving titles for non-ready scheduled targets.
- Shows schedule run/tick result summaries, including skipped count, failed/already-running states, missed run timestamps, next run timestamps, and task run links.
- Added focused schedule model tests for RRULE generation/parsing, form validation, payload building, cadence formatting, and run result rendering.

Behavior notes:

- The UI intentionally exposes only task-target schedules in this slice.
- The simple recurrence control emits `FREQ=HOURLY|DAILY|WEEKLY;INTERVAL=n`.
- Full schedule history remains out of scope because SQLite schedule history is not yet exposed as a durable API.
