## User Story

As a Team Orchestrator operator, I need durable schedule run history so I can inspect prior task and workflow-template schedule executions after refresh or restart.

## Scope

Persist app-state schedule execution attempts and expose them through schedule APIs and the console.

## Acceptance Criteria

- Adds durable app-state schedule run history for task and workflow-template schedules.
- Records status, started/finished timestamps, target type/id, task run id when present, mission id/task ids when present, missed/next run metadata, and failure details.
- Updates `GET /api/v1/schedules/:id/logs` or an equivalent schedule history endpoint to return app-state schedule history while preserving legacy schedule logs.
- Updates the console schedule UI to show recent run history for selected/configured schedules, including task run and mission links.
- Preserves existing schedule creation, pause/resume, run-now, tick, and workflow-template instantiation behavior.

## Non-Goals

- No hosted scheduler.
- No catch-up policy changes.
- No mission DAG execution changes.
- No analytics dashboard beyond recent schedule history.

## Engineering Handoff

Completed.

Implemented durable app-state schedule run history for task and workflow-template schedules:

- Added SQLite migration v5 for `schedule_run_history`, with target/run/mission/task metadata and schedule-scoped ordering.
- Added `ScheduleRunHistoryRepository` and exposed it through `AppStateDatabase`.
- Extended `ScheduleRunLog` and generated API component schemas with target type/id, run id, mission id, task ids, missed/next run metadata, reason, and failure details.
- Updated `LocalScheduleService` to record app-state schedule attempts for task success/failure, workflow-template success/failure, and in-process overlap skips.
- Updated `GET /api/v1/schedules/:id/logs` behavior through the existing service method to return app-state history merged with legacy JSONL logs, newest first.
- Updated the console schedule page with selected schedule rows and a Run History panel that links task runs and missions.
- Added focused service/API/model coverage for durable task and workflow-template schedule history.
