# Athena Console (Web UI)

The Athena Console is a centralized web UI for fleet management, session exploration, and policy administration. It provides a visual interface for operations that are otherwise managed via the CLI or API.

## Running the Console

To run the console locally, use the following command:

```bash
npm run dev
```

This will start both the API server and the Console development server concurrently. You can access the console at `http://localhost:5173` (or the URL provided by the Vite output).

## Core Features

### 1. Fleet Dashboard

The Fleet Dashboard provides a high-level overview of your Athena deployment, including:

- **Fleet Health**: Real-time status of agent pods and services.
- **Resource Utilization**: CPU and memory usage across the fleet.
- **Cost Monitoring**: Visualization of estimated costs for LLM usage and compute resources.

### 2. Session Explorer

The Session Explorer allows you to deep-dive into individual persona runs and sessions:

- **Real-time Transcript Streaming**: Watch agent turns and tool calls as they happen.
- **Artifact Gallery**: Browse and preview artifacts (e.g., reports, JSON results) generated by runs.
- **Work Queues**: Inspect the current state of the task queue for a given session.
- **Global Session Search**: Quickly find sessions by ID, persona name, or metadata.

### 3. Policy Editor

The Policy Editor provides a visual management interface for Athena's runtime policies:

- **Concurrency Limits**: View and update `maxConcurrentRuns` and other global limits.
- **Retry and Timeout Policies**: Configure how Athena handles failures and long-running tasks.
- **RBAC Management**: Manage roles, permissions, and identity mappings (when enabled).

### 4. A2A Flow Visualization

For complex agent-to-agent (A2A) interactions, the console provides:

- **Message Throughput**: Visualize the flow of messages between different personas.
- **DLQ Management**: Inspect and manage the Dead-Letter Queue (DLQ), allowing you to requeue or discard failed messages.

## Developing the Console

The Athena Console is built with Vite, React, and TypeScript. It is located in the `packages/console` directory.

### Project Structure

- `src/components/`: Shared UI components.
- `src/features/`: Domain-specific features (fleet, sessions, runs).
- `src/hooks/`: Shared React hooks.
- `src/services/`: API client and data fetching setup (using TanStack Query).
- `src/styles/`: CSS Modules and design tokens.

### Scripts

- `npm run dev`: Start the console in development mode.
- `npm run build`: Build the console for production.
- `npm run lint`: Run ESLint to check for code quality issues.
- `npm run typecheck`: Run TypeScript type checking.
