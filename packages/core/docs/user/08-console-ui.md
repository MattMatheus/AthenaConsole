# Team Orchestrator Console

The Team Orchestrator Console is the current web UI for agent creation, repository-connected work, run history, artifact review, runtime health, and policy administration. It provides a visual interface for operations that can also be managed through the core API or compatibility CLI.

## Running the Console

To run the console locally, use the following command:

```bash
npm run dev
```

This will start both the API server and the Console development server concurrently. You can access the console at `http://localhost:5173` (or the URL provided by the Vite output).

## Core Features

### 1. Operations Dashboard

The Operations Dashboard provides a high-level overview of local orchestration health, including:

- **Runtime Health**: Real-time status of active work and backend services.
- **Resource Utilization**: CPU and memory usage across the runtime.
- **Cost Monitoring**: Visualization of estimated costs for LLM usage and compute resources.

### 2. Run History

Run History allows you to inspect historical and live run records:

- **Real-time Transcript Streaming**: Watch agent turns and tool calls as they happen.
- **Artifacts**: Browse and preview artifacts (e.g., reports, JSON results) generated by runs.
- **Transcript Search**: Find run records by transcript text, operator profile, user, status, or date.
- **Task Run Links**: Jump from task, mission, and workflow run surfaces into task-run outputs and artifact previews.

### 3. Policy Editor

The Policy Editor provides a visual management interface for Athena's runtime policies:

- **Concurrency Limits**: View and update `maxConcurrentRuns` and other global limits.
- **Retry and Timeout Policies**: Configure how Athena handles failures and long-running tasks.
- **RBAC Management**: Manage roles, permissions, and identity mappings (when enabled).

### 4. Work Flow Diagnostics

For task and workflow execution diagnostics, the console provides:

- **Work Flow Inspection**: Visualize event traces for task, run, and workflow activity.
- **Failed Work Recovery**: Inspect failed work items, request retries, or discard terminal failures with audit notes.

## Developing the Console

The Team Orchestrator Console is built with Vite, React, and TypeScript. It is located in the `apps/console` directory.

### Project Structure

- `src/components/`: Shared UI components.
- `src/features/`: Domain-specific features (operations, run history, runs).
- `src/hooks/`: Shared React hooks.
- `src/services/`: API client and data fetching setup (using TanStack Query).
- `src/styles/`: CSS Modules and design tokens.

### Scripts

- `npm run dev`: Start the console in development mode.
- `npm run build`: Build the console for production.
- `npm run lint`: Run ESLint to check for code quality issues.
- `npm run typecheck`: Run TypeScript type checking.
