# Epic: Project Athena Web Console

**As a Project Athena User, I want a modern, performant web interface so that I can manage my agent fleet, debug complex workflows, and observe system health in real-time.**

## Problem Statement
Project Athena has a mature and robust API/CLI, but high-level orchestration, fleet management, and deep-dive session debugging are cognitively demanding in a terminal-only environment. A visual console is required to reduce "time to insight" and provide a centralized governance view for multi-user operations.

## User Personas
- **Platform Admin:** Needs to see aggregate fleet health, cost/quota utilization, and security audit trails.
- **Operator:** Needs to trigger workflows, monitor active runs, and jump into specific sessions to investigate agent reasoning or failures.
- **Persona Developer:** Needs to see real-time transcripts, symbolic navigation data, and artifact previews to refine agent logic.

## Success Metrics
- **Performance:** Initial Load (LCP) under 1.5s; Client-side transitions feel instantaneous.
- **Observability:** 100% of API resources (Runs, Sessions, Workflows, Events) are discoverable via the UI.
- **Usability:** Zero manual "API mapping" required; the UI should provide intuitive drill-downs from Fleet -> Run -> Session -> Transcript.

## Core Architectural Decisions
- **Framework:** React 18+ (TypeScript).
- **Styling:** Vanilla CSS (CSS Modules) with a focused set of Design Tokens (Colors, Spacing, Typography).
- **State Management:** TanStack Query (React Query) for server state; native React context for minimal UI state.
- **Routing:** React Router (v6+).
- **Visualization:** Low-weight SVG-based primitives for DAGs (workflows) and line charts (metrics).
- **Aesthetics:** "Engineering-First / Industrial" – Inspired by Ansible AWX and Apache Airflow. High contrast, high information density, left-side navigation with a toggleable hamburger menu, and collapsible sections for structured data.
