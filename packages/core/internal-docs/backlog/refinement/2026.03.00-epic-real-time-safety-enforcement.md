# Epic: Real-time Safety Enforcement

**As a Platform Admin, I want to enforce resource and network limits so that I can prevent agent-driven outages or security breaches.**

## Problem Statement
Isolation is not enough if an agent can spawn a fork-bomb or exfiltrate data via HTTP. We need active "fail-closed" guardrails that monitor agent behavior in real-time.

## Success Metrics
- **Resource Limits:** Automated termination of runs exceeding CPU/Memory/Disk quotas.
- **Network Gating:** Strict egress control (Allow-list only) for agent-generated network requests.
- **Policy Fail-Closed:** If the safety monitor fails, all active runs are immediately terminated.
