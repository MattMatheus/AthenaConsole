# Story: Implement Resource Quota Monitor and Enforcer

**As a Platform Admin, I want to kill runaway agent tasks that exceed their resource limits.**

## Problem Statement
Even in a sandbox, a malicious or buggy agent can consume 100% CPU or 10GB of RAM, impacting other tasks in the cluster. We need active enforcement of quotas.

## Acceptance Criteria
- `HarnessProfile` defines `cpuLimit`, `memoryLimit`, and `maxDuration`.
- The orchestrator monitors the sandbox stats in real-time.
- If a limit is breached, the sandbox is immediately terminated.
- The run is marked as `failed` with a specific `RESOURCE_QUOTA_EXCEEDED` error code.
- A safety event is emitted with the peak resource usage captured.

## Technical Constraints
- Monitoring should be lightweight (e.g., polling every 1-2 seconds) to avoid overhead.
- In K8s, this should leverage native `limits` in the Pod spec where possible.
