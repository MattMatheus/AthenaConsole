# Epic: Intent & Execution Decoupling

**As a Persona Developer, I want to separate user intent from execution configuration so that I can upgrade agent logic without changing the user's request.**

## Problem Statement
The current `RunRequest` mixes "What to do" (input) with "How to do it" (provider/model/tools). This makes it impossible to re-run the same user request with a different model version while maintaining a clean audit trail of the original intent.

## Success Metrics
- **Directive Independence:** `Directives` exist as immutable records of user intent.
- **Harness Portability:** `HarnessProfiles` can be applied to any Directive.
- **Comparative Runs:** Ability to see how two different Harnesses resolved the same Directive.

- `24.03-migrate-run-orchestrator-to-directive-harness-pattern`
