# Story: [Backend] Add Sandbox Lifecycle Telemetry Contracts

**As an operator, I need sandbox lifecycle telemetry and event metadata so I can diagnose startup latency, failures, and cleanup outcomes for isolated runs.**

## Status
* Ready

## Scope
* Add bounded telemetry/event fields for sandbox lifecycle.
* Preserve existing envelope/error semantics and compatibility.
* Update API schemas/artifacts from shared contracts where applicable.
* Document the new telemetry fields for operators.

## File Touchpoints
* `src/shared/contracts.ts`
* `src/control-plane/services.ts`
* `src/control-plane/api-contracts.ts` (re-export/metadata only)
* `src/control-plane/api-schemas.ts`

## Acceptance Criteria
* Sandbox events include phase and latency metadata with run/session correlation.
* Field additions are optional/backward-compatible for existing consumers.
* Generated schema artifact and schema drift checks pass.
* Event retention behavior remains bounded and unchanged in principle.
