# Story: Visual Policy Editor for Concurrency and Safety

**As a Platform Admin, I want a visual policy editor so that I can safely tune the platform's limits and guardrails.**

## Problem Statement
The global `PolicyDocument` controls critical safety features like concurrency limits and cost budgets. Managing this via raw JSON is error-prone and lacks validation, which could lead to platform-wide outages.

## Acceptance Criteria
- Form-based UI for editing all fields in ADR-15 policy document.
- Real-time validation (e.g., preventing negative timeouts or zero concurrency slots).
- "Preview Changes" view that shows a `diff` between the current and proposed policy.
- Integration with the `PolicyService` to apply updates with a human-readable audit comment.

## Technical Constraints
- The UI must dynamically pull the current schema version from the `PolicyService`.
- Must respect RBAC: Only `Admin` role can save changes.
