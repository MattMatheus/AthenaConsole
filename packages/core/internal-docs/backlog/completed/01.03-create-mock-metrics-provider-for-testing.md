# Story: Create Mock Metrics Provider

**As a developer, I want a mock implementation of the `FleetSummary` provider so that I can write isolated unit and integration tests for API consumers without needing a real backend.**

## Status
Completed on 2026-02-17.

## Acceptance Criteria
*   A `MockMetricsProvider` class is created in the test suite.
*   The mock provider can be configured to return different `FleetSummary` payloads, including variations with and without optional metrics.
*   The mock is used in at least one API-level test to verify the metrics endpoint.
