# Story: Launch @projectathena/pdk NPM Package

**As a Persona Developer, I want a typed SDK so that I can build personas with IDE support and fewer errors.**

## Problem Statement
Developing personas currently involves editing raw JSON and Markdown files. There is no type checking, leading to runtime errors when the orchestrator encounters malformed configurations.

## Acceptance Criteria
- `@projectathena/pdk` package created in the `packages/` or `libs/` directory.
- Exports TypeScript interfaces for:
    - `PersonaDefinition`: Schema for `persona.json`.
    - `Skill`: Schema for agent tool/capability definitions.
    - `Context`: Schema for document/prompt references.
- Includes a `definePersona()` helper that validates the config at runtime.
- Documentation for the SDK is included in the package README.

## Technical Constraints
- Must be a ESM-only package to match the rest of the Team Orchestrator codebase.
- Minimal external dependencies to keep the SDK lightweight.
