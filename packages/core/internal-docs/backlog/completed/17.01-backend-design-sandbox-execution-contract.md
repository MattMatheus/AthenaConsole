# Story: [Backend] Design and Wire Sandbox Execution Contract

**As a platform engineer, I need a control-plane execution backend contract for sandboxed runs so Athena can orchestrate isolated runtimes without leaking Kubernetes-specific logic into API handlers.**

## Status
* Decomposed into implementation slices (do not execute as a single story).

## Decomposition (Iteration-Sized Stories)
* `internal-docs/backlog/completed/16.04-backend-add-sandbox-interface-and-adapter-scaffold.md`
* `internal-docs/backlog/completed/16.05-backend-wire-sandbox-capability-routing-and-fail-closed-policy.md`
* `internal-docs/backlog/completed/16.06-backend-add-sandbox-lifecycle-telemetry-contracts.md`

## Scope
* Introduce a backend interface for sandbox claim/readiness/termination/cleanup.
* Add capability flags and no-op fallback behavior for non-sandbox environments.
* Add event payload extensions needed for sandbox lifecycle observability.
* Keep route handlers transport-only.

## File Touchpoints
* `src/control-plane/interfaces.ts`

* `src/control-plane/api-contracts.ts` (re-export updates only; no duplicated DTOs)
* `src/control-plane/api-schemas.ts` (strictness overrides only, if needed)
* `src/control-plane/generated-component-schemas.ts` (generated)

## Acceptance Criteria
* A `SandboxExecutionBackend` interface exists with claim, wait-ready, terminate, and cleanup operations.
* Control-plane services can branch by capability to sandbox vs existing execution path.
* High-security policy contexts fail closed when sandbox is required but unavailable.
* Sandbox lifecycle fields are emitted into bounded telemetry/event payloads.
* No handler-level business logic is introduced.

## Acceptance Tests
* Unit: backend interface adapter tests for success, transient failure, and terminal failure mapping.
* Unit: service orchestration tests for:
  * sandbox-enabled success path
  * sandbox-unavailable fallback (non-high-security)
  * sandbox-required fail-closed path
  * cancel/timeout termination semantics
* Contract/schema:
  * `npm run generate:schemas`
  * `npm run check:schemas`
* Regression:
  * `npm run typecheck`
  * `npm test`
