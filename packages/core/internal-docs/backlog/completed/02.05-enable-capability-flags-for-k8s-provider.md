# Story: Enable Capability Flags for K8s Provider

**As a developer, I want the `K8sMetricsProvider` to accurately report its capabilities so that API clients know they can display richer data visualizations for pod status and resource metrics.**

## Acceptance Criteria
*   The `K8sMetricsProvider`'s implementation of the capability-gating method returns `true` for `supportsPodStatus`.
*   The provider returns `true` for `supportsCpuMemMetrics` only if it can successfully connect to the K8s Metrics Server.
*   The API response correctly shows these capabilities when the `k8s` backend is active.
