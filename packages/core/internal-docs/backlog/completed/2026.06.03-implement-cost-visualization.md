# Story: Resource Usage and Cost Visualization

**As a Finance Manager, I want to see a cost breakdown of LLM usage so that I can manage our AI budget.**

## Problem Statement
LLM tokens are expensive. Without clear visibility into which personas or users are consuming the most tokens, it is impossible to optimize costs or identify inefficient agent logic.

## Acceptance Criteria
- Dashboard charts showing:
    - **Total Spend:** Estimated USD cost across all providers.
    - **Persona Breakdown:** Cost per persona (e.g., "code-review" vs "pm").
    - **Token Mix:** Ratio of Input vs. Output tokens.
- Support for "Custom Cost per 1K Tokens" configuration in the provider settings.
- Exportable "Cost Report" (CSV) for monthly billing cycles.

## Technical Constraints
- Cost calculation should be performed in the `FleetService` to avoid duplicating logic in the UI.
- Must handle multiple providers with different pricing models (e.g., tier-based or flat).
