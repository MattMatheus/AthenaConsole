# Story: Extract 'Prompt Construction' Logic from runPersona

**As a backend developer, I need to extract the prompt assembly logic from `runPersona` into a dedicated 'prompt construction' function.**

## Acceptance Criteria
*   A new function (e.g., `constructPrompt`) is created.
*   It is solely responsible for assembling the final prompt string to be sent to the model, including all diff/context assembly.
*   `runPersona` is updated to call this new function.
*   New unit tests are created to verify the prompt construction logic.
