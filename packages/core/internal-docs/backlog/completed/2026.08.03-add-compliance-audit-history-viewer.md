# Story: Compliance Audit History Viewer

**As a Compliance Officer, I want an immutable history of policy changes so that I can prove the system is being operated securely.**

## Problem Statement
For SOC2 or ISO audits, we must be able to prove who changed the security policies of the platform. A "current state" view is not enough; we need a "history of changes."

## Acceptance Criteria
- "Audit Trail" view in the Governance Dashboard.
- Lists every change to:
    - `PolicyDocument` (Concurrency, budgets).
    - `RBAC Roles` (Adding/removing permissions).
    - `Identity Assignments` (Who is an Admin).
- Each entry includes:
    - Timestamp.
    - Identity of the actor.
    - "Before" vs "After" diff.
    - Optional "Reason" comment.

## Technical Constraints
- Data must be pulled from the persistent `EventStore`.
- Audit records must be immutable (no delete/edit).
