# Story: Implement Docker Sandbox Execution Provider

**As a Developer, I want to run agents in local Docker containers so that I can test sandboxing on my machine.**

## Problem Statement
We need a local-first sandboxing solution. Direct execution on the host is risky during persona development. Docker provides a standard, easy-to-use isolation layer for local development.

## Acceptance Criteria
- `DockerExecutionProvider` implements `ExecutionBackend`.
- Spawns a container using a configurable base image (default: `node:20-slim`).
- Commands are executed as a non-root user.
- Container is automatically removed after the command finishes.
- Host networking is disabled (`--network none` by default).

## Technical Constraints
- Requires Docker to be installed and accessible via the local socket.
- Must use `exec` style execution to capture stdout/stderr separately.
