# Story: Define Distributed Lock Interface

**As a developer, I need a `DistributedLock` interface to abstract the logic for acquiring and releasing concurrency slots, so that we can support different backends for global policy enforcement.**

## Acceptance Criteria
*   An `IDistributedLock` interface is created.
*   The interface defines methods like `tryAcquire(lockName, leaseTime)` and `release(lockName)`.
*   The interface is designed to be pluggable into the policy enforcement logic.
*   The choice of lock provider (e.g., local, redis) can be configured at application startup.
