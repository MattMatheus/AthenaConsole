# Story: Template Trigger API and CLI Support

**As a User, I want to trigger a run from a template via the API or CLI.**

## Problem Statement
Once templates are defined, we need a clean UX for executing them with specific parameters.

## Acceptance Criteria
- `POST /api/v1/templates/:id/run` accepts a `params` object.
- The orchestrator resolves the template, injects the params, and triggers a standard run.
- CLI command `athena run --template <id> --param key1=val1 --param key2=val2`.
- CLI provides clear error messages if a required parameter is missing from the template call.

## Technical Constraints
- The `params` must be stored in the resulting `RunResult` for audit purposes.
