# Story: Persistent JSONL Event Store

**As an Auditor, I want system events to be stored on disk so that they are not lost on restart.**

## Problem Statement
The current `LocalEventService` is volatile. We need a durable record of all system activity (Run starts, failures, policy changes).

## Acceptance Criteria
- `LocalEventService` migrated to write to `events.jsonl`.
- Supports high-concurrency appends using a lock or dedicated writer.
- Provides a `list` method with cursor-based pagination that reads from the file.
- Events are structured as one JSON object per line.

## Technical Constraints
- Use atomic renames or streams to ensure log integrity during crashes.
- Ensure the state directory (`.athena/events/`) is created automatically.
