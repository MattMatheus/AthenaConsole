# Story: Add Workspace Mounting and Sync Logic for Containers

**As a Persona Developer, I want my repository files available inside the sandbox so the agent can work on the code.**

## Problem Statement
An isolated container is only useful if it has access to the files it needs to act upon. We need a reliable way to mount or sync the current workspace into the sandbox.

## Acceptance Criteria
- **Local (Docker):** Mounts the project directory as a volume.
- **Remote (K8s):** Uses an `initContainer` or `git-sync` to clone the repo/ref into a shared `EmptyDir` volume.
- Supports `ReadOnly` mounts to prevent the agent from accidentally modifying the host filesystem.
- The agent's working directory (`cwd`) is correctly set to the workspace root inside the container.

## Technical Constraints
- Must handle path mapping differences between the host and the container.
- Ensure that sensitive files (like `.env` or `.git`) are optionally excluded via a "sandbox ignore" list.
