# Story: Implement Workflow Observability API

**As an Operator, I want to see the progress of my multi-step workflows in real-time.**

## Problem Statement
A workflow with 10 steps is a "black box" until it finishes. We need visibility into which step is currently executing and which ones failed.

## Acceptance Criteria
- `GET /api/v1/workflows/run/:id` returns a detailed status of all nodes.
- Includes estimated time to completion based on historical step durations.
- Provides links to individual run artifacts for every completed step.
- CLI command `athena work status --workflow <id>` provides a visual summary of the graph progress.

## Technical Constraints
- Efficient polling or event-driven updates to avoid overloading the state store.
