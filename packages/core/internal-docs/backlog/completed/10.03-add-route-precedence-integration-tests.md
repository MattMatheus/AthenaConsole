# Story: Add Route Precedence Integration Tests

**As a backend developer, I need to add specific integration tests that verify correct route precedence for ambiguous paths, to prevent regressions in API behavior.**

## Acceptance Criteria
*   A new test file is created for route precedence testing.
*   The tests send requests to ambiguous URLs (e.g., `/api/v1/runs/summary` which could match both a static handler and a parameterized `/api/v1/runs/:id` handler).
*   The tests assert that the most specific handler is correctly invoked in all cases.
*   These tests run as part of the main API test suite.
