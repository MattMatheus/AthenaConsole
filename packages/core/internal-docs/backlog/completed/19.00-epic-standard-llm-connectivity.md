# Epic: Standard LLM Connectivity

**As a Persona Developer, I need standard LLM connectivity so that I can use Team Orchestrator with real-world models and verify persona behavior.**

## Problem Statement
Team Orchestrator currently lacks native support for industry-standard LLM APIs. The existing `HttpProvider` uses a proprietary flat schema, and the `MockProvider` returns plain text, which causes Persona runs to fail during JSON parsing.

## User Personas
- **Persona Developer (Dev):** Needs to see how their agents behave with real models.
- **Platform Engineer (Alex):** Needs a standard way to plug in different LLM backends (OpenAI, Ollama, etc.).

## Success Metrics
- **OpenAI Compatibility:** Ability to route turns to any OpenAI-compatible API (OpenAI, Groq, DeepSeek, Ollama).
- **Schema-Aware Mocking:** Mock provider can return valid JSON payloads that satisfy Persona schema requirements.
- **Zero-Config Onboarding:** Clear documentation and `.env` patterns for API keys and model selection.

## Included Stories (Proposed)
- `19.01-implement-openai-compatible-provider-adapter`
- `19.02-enhance-mock-provider-with-json-schema-support`
- `19.03-add-provider-configuration-documentation-and-dotenv-example`
