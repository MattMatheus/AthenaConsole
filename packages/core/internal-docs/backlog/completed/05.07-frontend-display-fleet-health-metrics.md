# Story: [Frontend] Display Fleet Health Metrics on Dashboard

**As an operator, I want the Fleet Dashboard to display uptime and error-rate health metrics so that I can quickly assess fleet reliability.**

## Acceptance Criteria
*   The dashboard summary UI renders `uptime` and `errorRate` from `FleetSummary` when present.
*   Values are formatted for readability (percentage-style display with sensible precision).
*   The UI handles missing metrics gracefully (fallback placeholder or hidden state).
*   Existing fleet summary/resource/cost sections remain backward-compatible and functional.
