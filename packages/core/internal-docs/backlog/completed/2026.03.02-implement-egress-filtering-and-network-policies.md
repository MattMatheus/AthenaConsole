# Story: Implement Egress Filtering and Network Policies

**As a Platform Admin, I want strict outbound network controls so that agents cannot exfiltrate data or reach unauthorized destinations.**

## Problem Statement
Sandboxing and quota controls reduce compute risk, but uncontrolled outbound traffic still enables data loss and command-and-control behavior.

## Acceptance Criteria
- Add sandbox egress filtering controls for Docker and K8s-backed runs.
- Support allow-list based destination policy (host/domain and optional port constraints).
- Enforce fail-closed behavior when network policy evaluation or enforcement fails.
- Surface egress policy decisions via control-plane event semantics.
- Add deterministic tests for blocked/allowed outbound behavior and cleanup paths.

## Technical Constraints
- Keep changes behind control-plane/backend boundaries.
- Preserve lock-guarded run-state transitions and cleanup invariants.
- Keep contract/schema evolution additive and backward-compatible.
