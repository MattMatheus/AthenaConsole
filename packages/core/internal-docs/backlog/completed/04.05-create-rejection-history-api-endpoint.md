# Story: Create Rejection History API Endpoint

**As an operator, I want a new API endpoint `/api/v1/rejections` so that I can programmatically query the history of runs that were rejected due to concurrency policies.**

## Acceptance Criteria
*   A new GET endpoint `/api/v1/rejections` is added to the API server.
*   The endpoint uses the `RejectionEventStore` to fetch events.
*   It supports pagination parameters (e.g., `?limit=100&offset=0`).
*   The endpoint returns a JSON array of `RunRejectionEvent` objects.
*   The new endpoint is documented in the API specification.
