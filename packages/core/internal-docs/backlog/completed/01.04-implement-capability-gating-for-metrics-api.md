# Story: Implement Capability Gating for Metrics API

**As a developer, I want the fleet metrics API endpoint to expose which optional metrics are supported by the current backend provider, so that UI clients can adapt their dashboards accordingly.**

## Status
Completed on 2026-02-17.

## Acceptance Criteria
*   The API response for fleet summary (e.g., `/api/v1/fleet/summary`) includes a `capabilities` object.
*   The `capabilities` object contains boolean flags like `supportsCpuMemMetrics` and `supportsPodStatus`.
*   The values of these flags are determined by the active metrics provider. (e.g., `local` provider would return `false` for `supportsCpuMemMetrics`).
*   API documentation is updated to explain the `capabilities` field.
