# Story: Extract 'Work' and 'Memory' Route Handlers

**As a backend developer, I need to extract the API logic for the 'work' and 'memory' route families into the new `APIRouter`.**

## Acceptance Criteria
*   A new file is created for the work and memory route handlers.
*   All logic for these endpoints is migrated to the new handlers.
*   These handlers are registered in the main `RouteTable`.
*   The old logic is removed from the original monolithic function.
*   Existing API tests for these endpoints continue to pass.
