# Story: Create Session Explorer Page Component

**As a frontend developer, I need a main `SessionExplorer` page that serves as the container for all the detailed views of a specific agent session.**

## Acceptance Criteria
*   A new page component (`SessionExplorerPage.tsx`) is created, taking a session ID from the URL.
*   The page uses the `SessionApiService` to fetch all data for the given session.
*   It displays loading and error states correctly.
*   It arranges the child components (Transcript, Work Queue, etc.) in a clear, tabbed, or sectioned layout.
