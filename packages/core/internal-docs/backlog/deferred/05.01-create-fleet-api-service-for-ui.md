# Story: Create Fleet API Service for UI

**As a frontend developer, I need a TypeScript service that encapsulates the logic for calling the Fleet API endpoints (`/fleet/summary`), so that my UI components can fetch data consistently and safely.**

## Acceptance Criteria
*   A new service file is created (e.g., `ui/src/services/FleetApiService.ts`).
*   The service has methods to fetch the fleet summary data.
*   It uses the TypeScript interfaces defined in the API contracts project for type safety.
*   It handles API errors gracefully.
