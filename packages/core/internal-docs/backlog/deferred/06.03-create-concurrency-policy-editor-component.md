# Story: Create Concurrency Policy Editor Component

**As an admin, I want a form in the Policy Editor to view and set the `maxConcurrentRuns` value, so that I can control the overall concurrency of the agent fleet.**

## Acceptance Criteria
*   A new component (`ConcurrencyPolicyEditor.tsx`) is created.
*   The component contains a number input field to display and modify the `maxConcurrentRuns` value.
*   It uses the `PolicyApiService` to fetch the current value on load and save the new value on submit.
*   It displays feedback to the user on successful save or on error.
