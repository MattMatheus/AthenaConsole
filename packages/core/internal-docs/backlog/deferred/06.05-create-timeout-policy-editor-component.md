# Story: Create Timeout Policy Editor Component

**As an admin, I want a form in the Policy Editor to set timeout limits for agent runs, so that I can prevent runaway processes.**

## Acceptance Criteria
*   A new component (`TimeoutPolicyEditor.tsx`) is created.
*   The component includes a form field (e.g., number input with units like seconds/minutes) for the run timeout value.
*   It uses the `PolicyApiService` to load and save the timeout policy.
