# Story: Create Session List Page

**As an operator, I need a page where I can see a list of active and recent sessions so that I can select one to investigate in the Session Explorer.**

## Acceptance Criteria
*   A new page component (`SessionListPage.tsx`) is created and added to the UI routing.
*   The page fetches and displays a list of sessions from a relevant API endpoint.
*   Each item in the list links to the `SessionExplorer` page for that specific session ID.
*   The list should be searchable or filterable if possible.
